Detailed Description

Header file for non-blocking SNMPv1 agent with UDP transport.

Version
1.0.0
Date
2025-11-07 đ

SNMP agent for ENERGIS RTOS. Owns a UDP socket (port 161), parses incoming PDUs and emits responses without blocking the scheduler. Time base is 10 ms via SNMP_Tick10ms(), used for TimeTicks.

@project ENERGIS - The Managed PDU Project for 10-Inch Rack @github https://github.com/DvidMakesThings/HW_10-In-Rack_PDU

◆ SNMP_Poll()

int SNMP_Poll ( int max_packets)

Service pending SNMP datagrams without blocking.

Parameters
max_packetsMaximum number of packets to process this call (1..N).
Returns
Number of processed packets (>=0).

Service pending SNMP datagrams without blocking.

Non-blocking service routine that processes up to max_packets SNMPv1 requests from the UDP socket bound to port 161, and emits corresponding GetResponse PDUs. This variant relies on the W5500-style datagram reader recvfrom_SNMP(), which already consumes the 8-byte UDP datagram header (src IP[4], src port[2], payload length[2]) and returns the pure ASN.1 payload starting with 0x30.

Robustness:

  • If no data is pending in the RX buffer, the function returns immediately.
  • If the per-call RTOS time budget elapses, the function returns early to avoid starving other tasks and the watchdog.
  • Source address and port are taken directly from recvfrom_SNMP() and used for the reply via sendto().
Parameters
[in]max_packetsMaximum number of datagrams to process in this call (>=1).
Returns
int Number of serviced packets in this call (0..max_packets).
