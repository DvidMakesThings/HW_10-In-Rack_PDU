Heartbeat Periods

Expected task heartbeat cadence in milliseconds.

These values guide HealthTask diagnostics and liveness expectations. Tasks should call Health_Heartbeat() at least as frequently as their period, and always within the liveness window controlled by HEALTH_SILENCE_MS.
