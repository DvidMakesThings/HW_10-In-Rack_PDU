Public API

Create and initialize a socket

Creates a new socket with the specified protocol and port. For TCP, the socket is put into SOCK_INIT state. For UDP, the socket is put into SOCK_UDP state.

Parameters
snSocket number (0-7)
protocolProtocol type:
  • Sn_MR_TCP: TCP socket
  • Sn_MR_UDP: UDP socket
  • Sn_MR_IPRAW: IP raw socket
  • Sn_MR_MACRAW: MAC raw socket
portLocal port number (0 = auto-assign from 0xC000)
flagSocket flags (SF_xxx combinations):
  • TCP: SF_TCP_NODELAY, SF_IO_NONBLOCK
  • UDP: SF_IGMP_VER2, SF_MULTI_ENABLE, SF_UNI_BLOCK, SF_IO_NONBLOCK
  • MACRAW: SF_ETHER_OWN
Returns
Socket number (sn) on success, negative error code on failure
Note
TCP sockets require IP address to be configured
Port 0 triggers auto-assignment starting from 0xC000
