Detailed Description

Hardware abstraction layer for front-panel pushbutton controls and selection LEDs.

Version
1.0.0
Date
2025-11-06

This driver provides low-level access to the ENERGIS PDU front panel controls:

  • Three pushbuttons (PLUS, MINUS, SET) with active-low inputs and pull-ups
  • Eight channel selection LEDs driven via MCP23017 GPIO expander

The driver uses direct GPIO access for button reads and delegates LED control to SwitchTask for thread-safe I2C operations. All functions are non-blocking and safe to call from any task context.

Hardware Configuration:

  • Buttons are active-low with internal pull-ups
  • Selection LEDs are controlled via SwitchTask message queue
  • No debouncing is performed (handled by ButtonTask)

◆ ButtonDrv_InitGPIO()

void ButtonDrv_InitGPIO ( void )

Initialize button GPIO pins and selection LED hardware.

Configures button GPIOs as inputs with pull-ups enabled:

  • BUT_PLUS: Channel increment button
  • BUT_MINUS: Channel decrement button
  • BUT_SET: Channel selection/action button

All selection LEDs are turned off after initialization. This function must be called once during system startup.

Parameters
None
Returns
None
Note
Thread-safe, but should only be called once during initialization
Requires SwitchTask to be ready for LED control
