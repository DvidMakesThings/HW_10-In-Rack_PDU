Escape a string for safe inclusion in JSON output.

Copies source string to destination buffer while escaping special characters that require escaping in JSON strings according to RFC 8259. Filters out non-printable characters and ensures the result is null-terminated. Stops copying when destination buffer is nearly full.

Escape Rules:

  • Double quote (") → \"
  • Backslash () → \
  • Newline (
    ) →
  • Carriage return (\r) → \r
  • Tab (\t) → \t
  • Non-printable chars (< 0x20 or > 0x7E) → omitted
Parameters
dstDestination buffer for escaped string
dst_lenSize of destination buffer in bytes (must be >= 1)
srcSource string to escape (null-terminated)
Returns
None (result written to dst and null-terminated)
Note
Always null-terminates dst, even if src is too long to fit.
If dst_len is 0 or dst is NULL, function returns immediately without error.
Stops copying with room for null terminator (dst[dst_len-1] = '\0').

const char * oc_state_to_string ( overcurrent_state_t state)
static

Convert overcurrent state enum to JSON string representation.

Maps overcurrent_state_t enum values to human-readable string literals for JSON output. Provides a default "UNKNOWN" string for invalid or future enum values.

Parameters
stateOvercurrent protection state enum value
Returns
Constant string pointer to state name (never NULL)

Mapping:

  • OC_STATE_NORMAL → "NORMAL"
  • OC_STATE_WARNING → "WARNING"
  • OC_STATE_CRITICAL → "CRITICAL"
  • OC_STATE_LOCKOUT → "LOCKOUT"
  • Other values → "UNKNOWN"
Note
Returned string is a compile-time constant; no allocation or copying.
Safe to use in JSON output without escaping (no special characters).
