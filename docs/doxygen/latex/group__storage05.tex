\doxysubsubsubsection{Detailed Description}
System event logging with separate error and warning ring buffers. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/14
\end{DoxyDate}
This module manages system event logs stored in EEPROM using dual ring buffer structures. Provides persistent logging of errors and warnings for diagnostics, troubleshooting, and compliance auditing.

Key Features\+:
\begin{DoxyItemize}
\item Separate ring buffers for errors and warnings
\item 16-\/bit event codes for compact storage
\item Automatic pointer wrapping for circular storage
\item Write pointer persistence across power cycles
\item Support for bulk read/write operations
\item Append-\/only design prevents event tampering
\end{DoxyItemize}

EEPROM Memory Layout\+: Two independent ring buffer regions\+:


\begin{DoxyEnumerate}
\item Error Log (EEPROM\+\_\+\+EVENT\+\_\+\+ERR\+\_\+\+START, EEPROM\+\_\+\+EVENT\+\_\+\+ERR\+\_\+\+SIZE bytes)\+:
\begin{DoxyItemize}
\item Offset 0-\/1\+: Write pointer (uint16\+\_\+t, entry index)
\item Offset 2+\+: Error codes (EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE bytes each)
\end{DoxyItemize}
\item Warning Log (EEPROM\+\_\+\+EVENT\+\_\+\+WARN\+\_\+\+START, EEPROM\+\_\+\+EVENT\+\_\+\+WARN\+\_\+\+SIZE bytes)\+:
\begin{DoxyItemize}
\item Offset 0-\/1\+: Write pointer (uint16\+\_\+t, entry index)
\item Offset 2+\+: Warning codes (EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE bytes each)
\end{DoxyItemize}
\end{DoxyEnumerate}

Event Code Format\+:
\begin{DoxyItemize}
\item Size\+: EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE bytes (typically 2 bytes for uint16\+\_\+t)
\item Structure\+: 16-\/bit packed event code via ERR\+\_\+\+MAKE\+\_\+\+CODE macro
\begin{DoxyItemize}
\item Bits 15-\/12\+: Module ID (identifies source subsystem)
\item Bits 11-\/8\+: Severity level (ERR\+\_\+\+SEV\+\_\+\+ERROR / ERR\+\_\+\+SEV\+\_\+\+WARNING)
\item Bits 7-\/4\+: Function ID (identifies specific function)
\item Bits 3-\/0\+: Error instance (distinguishes multiple errors in same function)
\end{DoxyItemize}
\end{DoxyItemize}

Ring Buffer Structure (per buffer)\+:
\begin{DoxyItemize}
\item First 2 bytes (EVENT\+\_\+\+LOG\+\_\+\+POINTER\+\_\+\+SIZE)\+: Write pointer
\begin{DoxyItemize}
\item Stores index of next entry to write
\item Automatically wraps to 0 when buffer fills
\item Persisted to EEPROM after each append
\end{DoxyItemize}
\item Remaining bytes\+: Event code array
\begin{DoxyItemize}
\item Each entry\+: EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE bytes (2 bytes for uint16\+\_\+t)
\item Number of entries\+: (BUFFER\+\_\+\+SIZE -\/ 2) / 2
\item Older entries overwritten when buffer wraps
\end{DoxyItemize}
\end{DoxyItemize}

Append Operation\+:
\begin{DoxyEnumerate}
\item Read current write pointer from buffer start
\item Validate pointer (clamp to 0 if out of range)
\item Calculate address for new entry\+: BASE + 2 + (ptr × ENTRY\+\_\+\+SIZE)
\item Write new event code to calculated address
\item Increment pointer (wrap to 0 if at end of buffer)
\item Write updated pointer back to buffer start
\item Oldest entry automatically overwritten on wrap
\end{DoxyEnumerate}

Error vs. Warning Classification\+:
\begin{DoxyItemize}
\item Errors\+: Critical faults requiring attention
\begin{DoxyItemize}
\item Overcurrent trips
\item I2C communication failures
\item EEPROM write errors
\item Watchdog resets
\item Ethernet link failures
\end{DoxyItemize}
\item Warnings\+: Non-\/critical events for awareness
\begin{DoxyItemize}
\item Temperature threshold crossings
\item MAC address repairs
\item CRC mismatches with successful recovery
\item Button long-\/press events
\item DHCP fallback to static IP
\end{DoxyItemize}
\end{DoxyItemize}

Bulk Operations\+:
\begin{DoxyItemize}
\item \doxylink{group__storage05_gabbe7eb05db9255f0b77b8d43ed6ee7c3}{EEPROM\+\_\+\+Write\+Event\+Logs()}\+: Bulk write entire error region (for restoration)
\item \doxylink{group__storage05_gad9c0aae90591df3b2bb552a2755ce7a9}{EEPROM\+\_\+\+Read\+Event\+Logs()}\+: Bulk read entire error region (for backup/analysis)
\item Used for firmware updates, factory reset, or diagnostics extraction
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item All read/write functions require eeprom\+Mtx held by caller
\item Prevents concurrent access corruption
\item Ensures atomic read-\/modify-\/write for pointer updates
\end{DoxyItemize}

Integration Points\+:
\begin{DoxyItemize}
\item All modules\+: Append error/warning codes via \doxylink{group__tasks10_ga78c530f9c7ec4d2330e6d1a092df6dc0}{Storage\+\_\+\+Enqueue\+Error\+Code()}
\item Storage\+Task\+: Processes queued codes and calls EEPROM append functions
\item Web interface\+: Retrieves historical logs for diagnostics page
\item SNMP\+: Provides event statistics via custom OIDs
\item Console commands\+: Reads and displays event logs
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item Module detects error or warning condition
\item Module calls \doxylink{group__tasks10_ga78c530f9c7ec4d2330e6d1a092df6dc0}{Storage\+\_\+\+Enqueue\+Error\+Code()} with \doxylink{group__config04_ga745daff0f1f8857ec240cab3479908d5}{ERR\+\_\+\+MAKE\+\_\+\+CODE()} value
\item Storage\+Task processes queue and calls\+: a. \doxylink{group__storage05_gaac46b7836e5834209a11390bf671aaea}{EEPROM\+\_\+\+Append\+Error\+Code()} for errors (ERR\+\_\+\+SEV\+\_\+\+ERROR) b. \doxylink{group__storage05_gab97b8ca8cca74eac342092d2e5cdb139}{EEPROM\+\_\+\+Append\+Warning\+Code()} for warnings (ERR\+\_\+\+SEV\+\_\+\+WARNING)
\item Web interface or SNMP reads historical logs\+: a. Call \doxylink{group__storage05_gad9c0aae90591df3b2bb552a2755ce7a9}{EEPROM\+\_\+\+Read\+Event\+Logs()} to bulk read error buffer b. Parse codes using write pointer to determine newest/oldest c. Decode codes using \doxylink{_e_r_r_o_r___c_o_d_e_8h}{error\+\_\+code.\+h} lookup tables
\end{DoxyEnumerate}

Pointer Management\+:
\begin{DoxyItemize}
\item Pointer tracks next write position (not last written position)
\item Valid pointer range\+: 0 to max\+\_\+entries-\/1
\item Corrupted pointer (out of range) clamped to 0
\item Empty buffer indicated by uninitialized EEPROM (all 0x\+FF)
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item Bounds checking on all buffer operations
\item Pointer validation before use
\item Write failures logged to debug console (not re-\/enqueued to avoid loops)
\item Failed writes leave pointer unchanged
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Event codes are 16-\/bit packed values via ERR\+\_\+\+MAKE\+\_\+\+CODE macro. 

Ring buffers overwrite oldest data when full (no overflow protection). 

Caller must interpret pointer to distinguish new vs. old entries. 

All operations require eeprom\+Mtx held by caller. 

Error logging failures are printed but not re-\/logged to prevent infinite loops.
\end{DoxyNote}

Append one error event code to error ring buffer with automatic wrapping. 

Primary function for logging critical errors. Implements circular buffer behavior with automatic pointer management and wrap-\/around. Reads current write pointer, writes new error code, increments pointer (with wrapping), and persists updated pointer to EEPROM.

Event Code Format\+:
\begin{DoxyItemize}
\item Size\+: EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE bytes (typically 2 bytes for uint16\+\_\+t)
\item Created via \doxylink{group__config04_ga745daff0f1f8857ec240cab3479908d5}{ERR\+\_\+\+MAKE\+\_\+\+CODE(module, severity, function, instance)}
\item Example\+: \doxylink{group__config04_ga745daff0f1f8857ec240cab3479908d5}{ERR\+\_\+\+MAKE\+\_\+\+CODE(\+ERR\+\_\+\+MOD\+\_\+\+STORAGE, ERR\+\_\+\+SEV\+\_\+\+ERROR, ERR\+\_\+\+FID\+\_\+\+ST\+\_\+\+NETWORK, 0x1)}
\end{DoxyItemize}

Operation Sequence\+:
\begin{DoxyEnumerate}
\item Read current write pointer from EEPROM (offset 0-\/1)
\item Validate pointer (clamp to 0 if out of range)
\item Calculate entry address\+: BASE + 2 + (pointer × EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE)
\item Write new error code to calculated address
\item Increment pointer\+: ptr++
\item If pointer at end of buffer\+: ptr = 0 (wrap to start)
\item Write updated pointer back to EEPROM (offset 0-\/1)
\end{DoxyEnumerate}

Ring Buffer Behavior\+:
\begin{DoxyItemize}
\item Buffer size\+: (EEPROM\+\_\+\+EVENT\+\_\+\+ERR\+\_\+\+SIZE -\/ 2) bytes
\item Number of entries\+: (EEPROM\+\_\+\+EVENT\+\_\+\+ERR\+\_\+\+SIZE -\/ 2) / EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE
\item When buffer fills, wraps to start and overwrites oldest entry
\item Pointer always indicates next write position, not last written
\end{DoxyItemize}

Typical Error Categories\+:
\begin{DoxyItemize}
\item I2C communication failures (EEPROM, MCP23017, W5500)
