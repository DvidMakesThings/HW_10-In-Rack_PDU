\doxysubsection{Detailed Description}
Container for all 8 channels of HLW8032 calibration data. 

Aggregates calibration records for all 8 power measurement channels into a single structure for bulk EEPROM storage. Includes CRC field for future data integrity validation (currently reserved).

Structure\+:
\begin{DoxyItemize}
\item channels\+: Array of 8 \doxylink{structhlw__calib__t}{hlw\+\_\+calib\+\_\+t} structures (328 bytes total)
\item crc\+: Reserved CRC byte for future integrity checking (1 byte)
\end{DoxyItemize}

Storage\+:
\begin{DoxyItemize}
\item Total size\+: 329 bytes (8 × 41 bytes + 1 byte CRC)
\item EEPROM location\+: EEPROM\+\_\+\+SENSOR\+\_\+\+CAL\+\_\+\+START (0x0400)
\item Region size\+: 336 bytes allocated (7 bytes spare for expansion)
\end{DoxyItemize}

Usage\+:
\begin{DoxyItemize}
\item Read on boot to populate Meter\+Task calibration
\item Written after UART calibration commands
\item Individual channels can be accessed directly via EEPROM offset
\item Bulk structure used for backup/restore operations
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Total structure size\+: 329 bytes. 

CRC field reserved for future use, not currently validated. 

Channel 0 at offset +0, Channel 1 at offset +41, etc. 
\end{DoxyNote}
