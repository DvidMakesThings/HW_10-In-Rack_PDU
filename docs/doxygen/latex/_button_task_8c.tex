Main button scanning and event processing task. 

Continuously polls button GPIOs, performs debouncing, manages the selection window, and executes button actions. Handles all button logic including short/long press detection, power state control, and event publishing.

Button Actions\+:
\begin{DoxyItemize}
\item PLUS/\+MINUS (first press)\+: Open selection window without changing selection
\item PLUS/\+MINUS (window active)\+: Move selection and refresh timeout
\item SET (short)\+: Toggle selected relay output
\item SET (long)\+: Clear error/warning logs and fault LED
\item PWR (long in RUN mode)\+: Enter standby mode
\item PWR (short in STANDBY)\+: Exit standby mode
\end{DoxyItemize}
