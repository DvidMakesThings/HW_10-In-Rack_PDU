\doxysubsubsection{Detailed Description}
Network stack manager for W5500 Ethernet, HTTP server, and SNMP agent. 

\begin{DoxyVersion}{Version}
1.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/07
\end{DoxyDate}
This module implements a Free\+RTOS task for managing all network operations on the PDU. It is the exclusive owner of the W5500 Ethernet controller and coordinates HTTP and SNMP services with robust link supervision and standby mode support.

Architecture\+:
\begin{DoxyItemize}
\item Single-\/owner model\+: Net\+Task has exclusive access to W5500 hardware
\item Manages three W5500 hardware sockets\+: HTTP (0), SNMP agent (1), SNMP trap (2)
\item Supervises PHY link status with automatic reinitialization on link-\/up events
\item Integrates with Power\+Mgr for standby mode support
\item Coordinates with Storage\+Task for network configuration loading
\item Provides visual feedback via ETH LED (solid when linked, blinking when down)
\end{DoxyItemize}

Key Features\+:
\begin{DoxyItemize}
\item W5500 Ethernet controller management (SPI, GPIO, reset sequencing)
\item HTTP web server for PDU control interface and metrics endpoint
\item SNMP agent for network management protocol support
\item SNMP trap sender for proactive event notifications
\item Robust link detection and automatic recovery from cable disconnection
\item Full reinitialization on each link-\/up event to prevent stale connections
\item Standby mode support\+: suspends all operations when system enters standby
\item ETH LED control\+: solid ON when linked, blinking at 1 Hz when unlinked
\item Graceful degradation\+: system operates normally even without Ethernet
\end{DoxyItemize}

Network Configuration\+:
\begin{DoxyItemize}
\item Loaded from EEPROM via Storage\+Task at boot
\item Supports both static IP and DHCP modes
\item Configurable IP address, subnet mask, gateway, DNS server
\item Fixed MAC address (device-\/specific or factory default)
\item Configuration cached for rapid reinitialization on link events
\end{DoxyItemize}

Link Supervision\+:
\begin{DoxyItemize}
\item Polls W5500 PHY status continuously during RUN mode
\item Detects link-\/up transitions\+: triggers full W5500 reset and service restart
\item Detects link-\/down transitions\+: enables ETH LED blinking indicator
\item Prevents ERR\+\_\+\+CONNECTION\+\_\+\+REFUSED after cable reconnection via full reinit
\item Short timeout guards prevent indefinite blocking during reinitialization
\end{DoxyItemize}

Service Management\+:
\begin{DoxyItemize}
\item HTTP server\+: processes incoming requests with cooperative scheduling
\item SNMP agent\+: polls for incoming requests, rate-\/limited to prevent starvation
\item Health monitoring\+: tracks long-\/blocking operations and reports to watchdog
\item Cooperative pacing\+: yields between HTTP and SNMP operations to maintain responsiveness
\end{DoxyItemize}

Standby Mode Behavior\+:
\begin{DoxyItemize}
\item When system enters STANDBY via \doxylink{group__misc3_ga40de5935f9ba85f9141a9243b4d02c87}{Power\+\_\+\+Enter\+Standby()}\+:
\begin{DoxyItemize}
\item W5500 held in hardware reset by power manager
\item All network processing suspended
\item Maintains reduced heartbeat (500ms) for watchdog
\end{DoxyItemize}
\item On exit from STANDBY via \doxylink{group__misc3_gafa726e9d0fc140faa3f54c6905ac2520}{Power\+\_\+\+Exit\+Standby()}\+:
\begin{DoxyItemize}
\item Detects state transition and calls \doxylink{_net_task_8c_a69d051e31c6438ed93d21deb141e4795}{net\+\_\+reinit\+\_\+from\+\_\+cache()}
\item Restores W5500 configuration and restarts services
\item Re-\/evaluates link status and updates ETH LED accordingly
\end{DoxyItemize}
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item Graceful boot without Ethernet\+: rest of system operates normally
\item Hardware init failure\+: enters safe loop with heartbeat only
\item Configuration load failure\+: applies factory defaults automatically
\item Link supervision\+: handles intermittent connections robustly
\item All failures logged via structured error codes to EEPROM
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item Call Net\+Task\+\_\+\+Init(true) during system initialization (after Storage\+Task)
\item Query readiness via \doxylink{group__tasks07_gac238017e1130a6a762cf67cf3d8228e4}{Net\+\_\+\+Is\+Ready()} before accessing network functions
\item Task autonomously manages W5500, HTTP, SNMP, and link supervision
\item No explicit shutdown needed; standby mode handled automatically
\end{DoxyEnumerate}

Integration Points\+:
\begin{DoxyItemize}
\item Storage\+Task\+: loads network configuration from EEPROM
\item Power\+Mgr\+: respects standby mode and coordinates W5500 reset control
\item Switch\+Task\+: controls ETH LED for visual link status feedback
\item Health monitor\+: sends heartbeat and reports long-\/blocking operations
\item HTTP handlers\+: serve web interface and metrics endpoint
\item SNMP handlers\+: respond to management queries and send traps
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Net\+Task must be initialized after Storage\+Task due to configuration dependency. 

No other task should access W5500 hardware or SPI interface directly. 

System continues operating normally even if Ethernet hardware fails. 

HTTP server runs on TCP port 80; SNMP agent on UDP port 161.
\end{DoxyNote}

Apply network configuration from Storage\+Task and initialize the W5500.

Create and start the Network Task with a deterministic enable gate. 

Creates the Net\+Task Free\+RTOS task and waits for Storage\+Task readiness before proceeding. Implements deterministic boot sequencing to ensure configuration is available before network initialization.

Initialization Sequence\+:
\begin{DoxyEnumerate}
\item Wait for Storage\+Task readiness with 5-\/second timeout
\item Spawn Net\+Task with 4KB stack at NETTASK\+\_\+\+PRIORITY
\item Task internally waits for \doxylink{group__tasks10_gafeb6e0067e67c68af21f0eeae1d1279a}{storage\+\_\+wait\+\_\+ready()} before loading config
\item Task applies network config and starts HTTP/\+SNMP services
\end{DoxyEnumerate}


\begin{DoxyParams}[1]{Parameters}

\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
pd\+PASS on successful initialization or when skipped (enable=false). 

pd\+FAIL if task creation fails.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
Call after Switch\+Task\+\_\+\+Init(true) in boot sequence (step 6/7). 

Logs error codes on failure via error logger if enabled. 

Idempotent\+: safe to call multiple times, creates resources only once. 

Task begins autonomous operation immediately after creation.
