\doxysubsection{Detailed Description}
\begin{DoxyAuthor}{Author}
Dvid\+Makes\+Things -\/ David Sipos
\end{DoxyAuthor}
\begin{DoxyVersion}{Version}
2.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/30
\end{DoxyDate}
Provides a single FIFO-\/serialized execution path for all I2C transactions across both controllers (i2c0 and i2c1). Callers use synchronous wrappers that submit work to a bus task and block until completion, eliminating interleaving and reducing race conditions under load.

v2.\+1.\+0 Changes\+:
\begin{DoxyItemize}
\item Added I2\+C0 transaction tracing to debug display MCP reset issue
\item Logs all writes to I2\+C0 with address, register, and value
\end{DoxyItemize}
