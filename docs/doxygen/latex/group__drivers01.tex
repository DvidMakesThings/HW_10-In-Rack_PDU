\doxysubsubsection{Detailed Description}
Centralized, serialized I2C access with synchronous wrappers. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/17
\end{DoxyDate}
Exposes synchronous wrappers around Pico SDK I2C functions that are serialized through a single FIFO/\+Task, ensuring no interleaved accesses across controllers. This improves determinism under high load (e.\+g. SNMP stress) and avoids re-\/entrancy concerns.

Usage\+:
\begin{DoxyItemize}
\item Call \doxylink{group__drivers01_ga8bf0403f2c78483c3afc9ffea67c425f}{I2\+C\+\_\+\+Bus\+Init()} once during system startup
\item Use i2c\+\_\+bus\+\_\+\texorpdfstring{$\ast$}{*} helpers instead of direct Pico SDK calls
\item Optional legacy lock/unlock are still available for compatibility
\end{DoxyItemize}

Thread-\/safety\+:
\begin{DoxyItemize}
\item All functions are safe to call from multiple tasks; requests are queued.
\end{DoxyItemize}
