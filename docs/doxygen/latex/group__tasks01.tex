\doxysubsubsection{Detailed Description}
Button input handling with debouncing and selection window management. 

\begin{DoxyVersion}{Version}
1.\+0.\+1 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/08
\end{DoxyDate}
This module implements a Free\+RTOS task for handling physical button inputs on the PDU. It provides debounced button reading, selection window management with visual feedback, and power state control through button combinations.

Key Features\+:
\begin{DoxyItemize}
\item Polls PLUS, MINUS, SET, and PWR button GPIOs at configurable intervals
\item Software debouncing with configurable timing thresholds
\item Distinction between short and long press events for SET and PWR buttons
\item Selection window with timeout and LED blinking feedback
\item Event queue for inter-\/task communication
\item Power management integration for standby mode control
\end{DoxyItemize}

Button Behavior\+:
\begin{DoxyItemize}
\item PLUS\+: Move selection right (wraps around), only when window is active
\item MINUS\+: Move selection left (wraps around), only when window is active
\item SET (short)\+: Toggle selected relay output, opens window if closed
\item SET (long)\+: Clear error/warning logs and fault LED
\item PWR (long)\+: Enter standby mode from normal operation
\item PWR (short)\+: Exit standby mode when in standby
\end{DoxyItemize}

The selection window provides visual feedback via blinking LEDs and automatically closes after a configurable timeout period. The task operates without interrupts, using polling to maintain predictable real-\/time behavior.

Button scanning period in milliseconds. 

Defines how frequently the task polls button GPIO states. Lower values provide faster response but increase CPU usage. Typical range\+: 5-\/20ms.

Selection LED blink period in milliseconds.

Controls the on/off cycle time for the selection indicator LED during the active selection window. Must be long enough to be visible to users.

Selection window timeout in milliseconds.

Duration for which the selection window remains open after the last button interaction. After timeout, LEDs turn off and window closes automatically.

Storage task readiness timeout in milliseconds.

Maximum time to wait for Storage\+Task initialization during bring-\/up sequence. Button\+Task initialization fails if storage is not ready within this period.

Initialize and start the button handling task. 

Creates the Button\+Task Free\+RTOS task, initializes button GPIOs, sets up the event queue, and configures the LED blink timer. Implements deterministic initialization with storage readiness gate.

Initialization sequence\+:
\begin{DoxyEnumerate}
\item Initializes button GPIO pins with pull-\/ups
\item Waits for Storage\+Task readiness (with timeout)
\item Initializes power manager
\item Creates button event queue (32 events deep)
\item Creates and starts LED blink timer
\item Spawns Button\+Task with configured priority
\end{DoxyEnumerate}
