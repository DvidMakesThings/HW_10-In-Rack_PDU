\doxysubsubsubsection{Detailed Description}
Energy consumption logging with ring buffer persistence. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/14
\end{DoxyDate}
This module manages historical energy consumption data stored in EEPROM using a ring buffer structure. Provides periodic logging of energy measurements for trend analysis and capacity planning.

Key Features\+:
\begin{DoxyItemize}
\item Ring buffer for energy consumption records
\item Automatic pointer wrapping for circular storage
\item Fixed-\/size records for predictable memory usage
\item Write pointer persistence across power cycles
\item Support for bulk read/write operations
\end{DoxyItemize}

EEPROM Memory Layout (EEPROM\+\_\+\+ENERGY\+\_\+\+MON\+\_\+\+START, total size varies)\+:
\begin{DoxyItemize}
\item Offset 0-\/1\+: Write pointer (uint16\+\_\+t, entry index)
\item Offset 2+\+: Energy records (ENERGY\+\_\+\+RECORD\+\_\+\+SIZE bytes each)
\end{DoxyItemize}

Ring Buffer Structure\+:
\begin{DoxyItemize}
\item First 2 bytes (ENERGY\+\_\+\+MON\+\_\+\+POINTER\+\_\+\+SIZE)\+: Write pointer
\begin{DoxyItemize}
\item Stores index of next record to write
\item Automatically wraps to 0 when buffer fills
\item Persisted to EEPROM after each append
\end{DoxyItemize}
\item Remaining bytes\+: Energy record array
\begin{DoxyItemize}
\item Each record\+: ENERGY\+\_\+\+RECORD\+\_\+\+SIZE bytes
\item Number of records\+: (EEPROM\+\_\+\+ENERGY\+\_\+\+MON\+\_\+\+SIZE -\/ 2) / ENERGY\+\_\+\+RECORD\+\_\+\+SIZE
\item Older records overwritten when buffer wraps
\end{DoxyItemize}
\end{DoxyItemize}

Energy Record Format\+:
\begin{DoxyItemize}
\item Size\+: ENERGY\+\_\+\+RECORD\+\_\+\+SIZE bytes (defined in \doxylink{_c_o_n_f_i_g_8h}{config.\+h})
\item Contents\+: Application-\/specific energy data structure
\item Typically includes\+: timestamp, channel ID, energy counter, power metrics
\item Record structure defined by Meter\+Task
\end{DoxyItemize}

Append Operation\+:
\begin{DoxyEnumerate}
\item Read current write pointer from EEPROM
\item Calculate address for new record\+: BASE + 2 + (ptr × ENERGY\+\_\+\+RECORD\+\_\+\+SIZE)
\item Write new energy record to calculated address
\item Increment pointer (wrap to 0 if at end of buffer)
\item Write updated pointer back to EEPROM
\item Oldest record automatically overwritten on wrap
\end{DoxyEnumerate}

Bulk Operations\+:
\begin{DoxyItemize}
\item \doxylink{group__storage04_ga2d726f82a082d5cdd3ae6b1bfaab1ce8}{EEPROM\+\_\+\+Write\+Energy\+Monitoring()}\+: Bulk write entire region (for restoration)
\item \doxylink{group__storage04_ga9fb1f24e48771317aaa7c8b6c02c9786}{EEPROM\+\_\+\+Read\+Energy\+Monitoring()}\+: Bulk read entire region (for backup/analysis)
\item Used for firmware updates, factory reset, or data extraction
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item All read/write functions require eeprom\+Mtx held by caller
\item Prevents concurrent access corruption
\item Ensures atomic read-\/modify-\/write for pointer updates
\end{DoxyItemize}

Integration Points\+:
\begin{DoxyItemize}
\item Meter\+Task\+: Periodically appends energy records (e.\+g., hourly)
\item Web interface\+: Retrieves historical data for charts
\item SNMP\+: Provides energy statistics via custom OIDs
\item Storage Task\+: Provides eeprom\+Mtx for thread-\/safe access
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item Meter\+Task accumulates energy measurements
\item On logging interval (e.\+g., every hour)\+: a. Pack measurements into energy record structure b. Call \doxylink{group__storage04_ga718d1f1b5a07b4a0afee080ae1b18f2d}{EEPROM\+\_\+\+Append\+Energy\+Record()} to persist
\item Web interface or SNMP reads historical records\+: a. Call \doxylink{group__storage04_ga9fb1f24e48771317aaa7c8b6c02c9786}{EEPROM\+\_\+\+Read\+Energy\+Monitoring()} to bulk read b. Parse records using write pointer to determine newest/oldest
\end{DoxyEnumerate}

Pointer Management\+:
\begin{DoxyItemize}
\item Pointer tracks next write position (not last written position)
\item Valid pointer range\+: 0 to max\+\_\+entries-\/1
\item Corrupted pointer (out of range) clamped to 0
\item Empty buffer indicated by uninitialized EEPROM (all 0x\+FF)
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item Bounds checking on all buffer operations
\item Pointer validation before use
\item Write failures logged as ERR\+\_\+\+SEV\+\_\+\+ERROR
\item Failed writes leave pointer unchanged
\item Error codes enqueued to event log
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Energy record format is application-\/defined via ENERGY\+\_\+\+RECORD\+\_\+\+SIZE. 

Ring buffer overwrites oldest data when full (no overflow protection). 

Caller must interpret pointer to distinguish new vs. old records. 

All operations require eeprom\+Mtx held by caller.
\end{DoxyNote}

Append one energy record to ring buffer with automatic wrapping. 

Primary function for logging periodic energy measurements. Implements circular buffer behavior with automatic pointer management and wrap-\/around. Reads current write pointer, writes new record, increments pointer (with wrapping), and persists updated pointer to EEPROM.

Operation Sequence\+:
\begin{DoxyEnumerate}
\item Read current write pointer from EEPROM (offset 0-\/1)
\item Calculate record address\+: BASE + 2 + (pointer × ENERGY\+\_\+\+RECORD\+\_\+\+SIZE)
\item Write new energy record to calculated address
\item Increment pointer\+: ptr++
\item If pointer at end of buffer\+: ptr = 0 (wrap to start)
\item Write updated pointer back to EEPROM (offset 0-\/1)
\end{DoxyEnumerate}

Ring Buffer Behavior\+:
\begin{DoxyItemize}
\item Buffer size\+: (EEPROM\+\_\+\+ENERGY\+\_\+\+MON\+\_\+\+SIZE -\/ 2) bytes
\item Number of records\+: (EEPROM\+\_\+\+ENERGY\+\_\+\+MON\+\_\+\+SIZE -\/ 2) / ENERGY\+\_\+\+RECORD\+\_\+\+SIZE
\item When buffer fills, wraps to start and overwrites oldest record
\item Pointer always indicates next write position, not last written
\end{DoxyItemize}

Pointer Validation\+:
\begin{DoxyItemize}
\item Out-\/of-\/range pointers clamped to 0 (guards against corruption)
\item Max valid pointer\+: (buffer\+\_\+size / ENERGY\+\_\+\+RECORD\+\_\+\+SIZE) -\/ 1
\item Corrupted pointer triggers error log but operation continues
\end{DoxyItemize}
