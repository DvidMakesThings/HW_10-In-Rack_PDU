\doxysubsubsection{Detailed Description}
Hardware bring-\/up sequencing task implementation. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/01-\/01
\end{DoxyDate}
Init\+Task runs at highest priority during system boot to\+:
\begin{DoxyEnumerate}
\item Initialize all hardware in proper sequence
\item Probe peripherals to verify communication
\item Create subsystem tasks in dependency order
\item Wait for subsystems to report ready
\item Apply saved configuration (relay states) on startup
\item Delete itself when system is fully operational
\end{DoxyEnumerate}

Create and start the Init\+Task. 

Creates the high-\/priority initialization task responsible for hardware bring-\/up and subsystem creation. Runs during early boot, then deletes itself once the system reports ready.

\begin{DoxyNote}{Note}
Call from {\ttfamily main()} before {\ttfamily v\+Task\+Start\+Scheduler()}. 

Deterministic sequencing\+: creates tasks in dependency order and waits for readiness.
\end{DoxyNote}
