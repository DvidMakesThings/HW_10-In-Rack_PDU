\doxysubsection{Detailed Description}
Per-\/channel calibration parameters for HLW8032 power meter IC. 

Stores calibration factors and hardware parameters for one HLW8032 power measurement channel. Each PDU has 8 independent channels requiring individual calibration. Calibration performed via UART commands using known voltage and current references.

Calibration Factors\+:
\begin{DoxyItemize}
\item voltage\+\_\+factor\+: VF multiplier for voltage calculation (default\+: 0.\+596)
\begin{DoxyItemize}
\item Converts HLW8032 voltage register to actual volts
\item Derived from\+: V\+\_\+actual / V\+\_\+register during calibration
\end{DoxyItemize}
\item current\+\_\+factor\+: CF multiplier for current calculation (default\+: 14.\+871)
\begin{DoxyItemize}
\item Converts HLW8032 current register to actual amps
\item Derived from\+: I\+\_\+actual / I\+\_\+register during calibration
\end{DoxyItemize}
\end{DoxyItemize}

Zero-\/\+Point Offsets\+:
\begin{DoxyItemize}
\item voltage\+\_\+offset\+: Zero-\/load voltage correction in volts
\begin{DoxyItemize}
\item Compensates for ADC offset error
\item Measured with no load, subtracted from readings
\end{DoxyItemize}
\item current\+\_\+offset\+: Zero-\/load current correction in amps
\begin{DoxyItemize}
\item Compensates for ADC offset and leakage
\item Measured with no load, subtracted from readings
\end{DoxyItemize}
\end{DoxyItemize}

Hardware Parameters\+:
\begin{DoxyItemize}
\item r1\+\_\+actual\+: Measured high-\/side voltage divider resistor (default\+: 1880kΩ)
\item r2\+\_\+actual\+: Measured low-\/side voltage divider resistor (default\+: 1kΩ)
\item shunt\+\_\+actual\+: Measured current sense shunt resistor (default\+: 0.\+001Ω)
\end{DoxyItemize}

Calibration Flags\+:
\begin{DoxyItemize}
\item calibrated\+: 0x\+CA if voltage/current calibration complete, 0x\+FF otherwise
\item zero\+\_\+calibrated\+: 0x\+CA if zero-\/point calibration complete, 0x\+FF otherwise
\end{DoxyItemize}

Reserved\+:
\begin{DoxyItemize}
\item 5 bytes reserved for future expansion and structure alignment
\end{DoxyItemize}

Calibration Workflow\+:
\begin{DoxyEnumerate}
\item Measure actual resistor values and update r1/r2/shunt
\item Apply known voltage, measure, calculate voltage\+\_\+factor
\item Apply known current, measure, calculate current\+\_\+factor
\item Remove load, measure offsets, store voltage/current\+\_\+offset
\item Set calibrated flags to 0x\+CA
\item Write structure to EEPROM for channel
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
Structure size\+: 41 bytes per channel. 

Total storage for 8 channels\+: 328 bytes + 1 byte CRC = 329 bytes. 

Floats stored in IEEE 754 single-\/precision format (4 bytes each). 
\end{DoxyNote}
