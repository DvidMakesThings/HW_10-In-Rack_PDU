Init\+Task runs at highest priority during system boot to\+:
\begin{DoxyEnumerate}
\item Initialize all hardware in proper sequence
\item Probe peripherals to verify communication
\item Create subsystem tasks in dependency order
\item Wait for subsystems to report ready
\item Apply saved configuration (relay states) on startup
\item Delete itself when system is fully operational
\end{DoxyEnumerate}

Init\+Task main routine that performs the full bring-\/alive sequence. 

Sequence implemented exactly as specified\+: 1) Boot banner + HW init (GPIO, tick/watchdog standby, UART/\+SPI/\+I2C, ADC). 2) Rail check (3V3/5V) and peripheral probes\+:
\begin{DoxyItemize}
\item MCP23017 x3 (I2C)
\item CAT24\+C256 EEPROM (read sys-\/info/checksum block)
\item HLW8032 power meter (expect sane response if available)
\item W5500 (read VERSIONR) 3) Subsystem initialization in strict dependency order\+:
\item Logger\+Task (captures all subsequent logs)
\item Storage\+Task (EEPROM owner; loads/validates config)
\item Switch\+Task (MCP owner; applies SAFE state) \mbox{[}optional\mbox{]}
\item Button\+Task (front-\/panel scan) \mbox{[}optional\mbox{]}
\item Meter\+Task (HLW8032 polling)
\item Net\+Task (W5500 + HTTP/\+SNMP using loaded config)
\item Console\+Task (UART/\+USB-\/\+CDC console online)
\item Health\+Task (watchdog, heartbeats) \mbox{[}optional\mbox{]} 4) Configuration distribution\+:
\item Wait for Storage\+Task -\/\texorpdfstring{$>$}{>} config ready
\item Fetch validated network config and passively rely on Net\+Task to use it
\item Apply saved relay states (power-\/on configuration) 5) Finalization\+:
\item LEDs to indicate RUNNING
\item Log "{}\+System bring-\/alive complete"{} and self-\/delete
\end{DoxyItemize}
