\doxysubsubsection{Detailed Description}
Power metering and system telemetry monitoring task with HLW8032 interface. 

\begin{DoxyVersion}{Version}
1.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/15
\end{DoxyDate}
This module implements a Free\+RTOS task for power monitoring and system telemetry collection. It is the exclusive owner of the HLW8032 power measurement peripheral and the RP2040 ADC subsystem, providing centralized measurement data to other tasks.

Architecture\+:
\begin{DoxyItemize}
\item Single-\/owner model\+: Meter\+Task has exclusive access to HLW8032 and ADC hardware
\item Polls HLW8032 at 25 Hz in round-\/robin fashion across 8 relay channels
\item Samples system ADC telemetry at 5 Hz (die temperature, VUSB, 12V supply)
\item Publishes power measurements via Free\+RTOS queue for consumer tasks
\item Maintains cached telemetry accessible via non-\/blocking getter APIs
\item Implements energy accumulation in k\+Wh and relay uptime tracking
\end{DoxyItemize}

Key Features\+:
\begin{DoxyItemize}
\item Per-\/channel power measurements (voltage, current, active power, power factor)
\item Energy accumulation with millisecond-\/resolution integration
\item Relay uptime tracking per channel
\item System health monitoring (die temperature, supply voltages)
\item Standby mode support\+: pauses measurements to reduce CPU load
\item Configurable per-\/device temperature calibration (1-\/point and 2-\/point)
\item Overcurrent protection integration with real-\/time current summation
\item Thread-\/safe telemetry access without blocking measurement loop
\end{DoxyItemize}

Measurement Flow\+:
\begin{DoxyEnumerate}
\item HLW8032 polling\+: 40ms period, 8 channels × \texorpdfstring{$\sim$}{\string~}5ms each
\item Instantaneous values cached per-\/channel after each poll slice
\item Energy integration\+: power × time accumulated in k\+Wh
\item Power factor calculation\+: P / (V × I) clamped to \mbox{[}0, 1\mbox{]}
\item Telemetry publication\+: every 5th sample (\texorpdfstring{$\sim$}{\string~}200ms) to queue
\item ADC sampling\+: 200ms period for system telemetry (temp, voltages)
\end{DoxyEnumerate}

Standby Mode Behavior\+:
\begin{DoxyItemize}
\item When system enters standby via \doxylink{group__misc3_ga40de5935f9ba85f9141a9243b4d02c87}{Power\+\_\+\+Enter\+Standby()}\+:
\begin{DoxyItemize}
\item Stops all HLW8032 polling to prevent relay state queries
\item Stops ADC sampling to reduce power consumption
\item Maintains heartbeat at reduced rate (500ms) for watchdog
\end{DoxyItemize}
\item On exit from standby via \doxylink{group__misc3_gafa726e9d0fc140faa3f54c6905ac2520}{Power\+\_\+\+Exit\+Standby()}\+:
\begin{DoxyItemize}
\item Detects state transition and resumes normal operation
\end{DoxyItemize}
\end{DoxyItemize}

Temperature Calibration\+:
\begin{DoxyItemize}
\item Supports uncalibrated mode (RP2040 typical values)
\item Single-\/point calibration\+: adjusts offset at known ambient temperature
\item Two-\/point calibration\+: derives slope and intercept from two references
\item Calibration parameters persisted to EEPROM and loaded at boot
\item API provides compute and apply functions for calibration workflow
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item Call Meter\+Task\+\_\+\+Init(true) during system initialization (after Net\+Task)
\item Query readiness via \doxylink{group__tasks06_gaacb98f39434e19bddfcdc0e0b555bd50}{Meter\+\_\+\+Is\+Ready()} before accessing telemetry
\item Use \doxylink{group__tasks06_ga18b328d88256e730d39d6a33ea78d399}{Meter\+Task\+\_\+\+Get\+Telemetry()} for per-\/channel measurements (non-\/blocking)
\item Use \doxylink{group__tasks06_ga909c8be3f0ce184e2cd1045bc29e0e30}{Meter\+Task\+\_\+\+Get\+System\+Telemetry()} for ADC values (non-\/blocking)
\item Optional\+: set calibration with \doxylink{group__tasks06_ga3f1131031850b69b057eeb4f8db3a4b9}{Meter\+Task\+\_\+\+Set\+Temp\+Calibration()} after EEPROM load
\item Consumer tasks can read from q\+\_\+meter\+\_\+telemetry queue or use getter APIs
\end{DoxyEnumerate}

Integration Points\+:
\begin{DoxyItemize}
\item HLW8032 driver\+: exclusive owner, calls \doxylink{group__drivers04_ga0b3a5c410541deaf144c3e33d4b65175}{hlw8032\+\_\+poll\+\_\+once()} in loop
\item Overcurrent protection\+: updates OCP module with total current each cycle
\item Power manager\+: respects standby mode to stop measurements
\item Health monitor\+: sends heartbeat at configured interval
\item EEPROM storage\+: loads/stores temperature calibration parameters
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Meter\+Task must be initialized after Net\+Task due to deterministic sequencing. 

No other task should access ADC or HLW8032 hardware directly. 

Telemetry queue depth is 16 samples; older data discarded if consumers lag. 

Energy accumulation starts from zero at boot and persists during runtime only.
\end{DoxyNote}

Query active temperature calibration parameters and inferred mode. 

Retrieves the currently active temperature calibration parameters and infers the calibration mode based on comparison with RP2040 typical values. Useful for diagnostics, displaying calibration status, and verifying loaded parameters.

Mode Inference Logic\+:
\begin{DoxyItemize}
\item Mode 0 (NONE)\+: All parameters match RP2040 typicals (V0=0.\+706, S=0.\+001721, OFFSET=0)
\item Mode 1 (1PT)\+: V0 and S match typicals, but OFFSET ≠ 0 (offset-\/only calibration)
\item Mode 2 (2PT)\+: V0 or S differ from typicals (slope+intercept calibration)
\end{DoxyItemize}

Comparison uses small epsilons to account for floating-\/point precision\+:
\begin{DoxyItemize}
\item V0 epsilon\+: 0.\+5 mV
\item Slope epsilon\+: 20 µ\+V/°C
\item Offset epsilon\+: 0.\+005 °C
\end{DoxyItemize}
