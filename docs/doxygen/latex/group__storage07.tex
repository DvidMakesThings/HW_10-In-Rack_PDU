\doxysubsubsubsection{Detailed Description}
Network settings with CRC validation and MAC repair. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/14
\end{DoxyDate}
This module manages network configuration parameters stored in EEPROM with CRC-\/8 data integrity protection and automatic MAC address repair. It handles both system information (firmware version) and network settings (IP, MAC, gateway, DNS, DHCP) with separate EEPROM address spaces.

Key Features\+:
\begin{DoxyItemize}
\item Network configuration persistence with CRC-\/8 validation
\item Automatic MAC address repair for corrupted values
\item System information storage with integrity checking
\item Fallback to defaults on read failures
\item Thread-\/safe access with mutex protection
\end{DoxyItemize}

EEPROM Memory Layout\+:
\begin{DoxyEnumerate}
\item System Info Section (EEPROM\+\_\+\+SYS\+\_\+\+INFO\+\_\+\+START)\+:
\begin{DoxyItemize}
\item Size\+: EEPROM\+\_\+\+SYS\+\_\+\+INFO\+\_\+\+SIZE bytes
\item Contents\+: Firmware version string (SWVERSION)
\item Optional CRC-\/8 appended for validation
\end{DoxyItemize}
\item Network Config Section (EEPROM\+\_\+\+USER\+\_\+\+NETWORK\+\_\+\+START)\+:
\begin{DoxyItemize}
\item Size\+: 24 bytes (EEPROM\+\_\+\+USER\+\_\+\+NETWORK\+\_\+\+SIZE)
\item Layout\+: MAC(6) + IP(4) + Subnet(4) + Gateway(4) + DNS(4) + DHCP(1) + CRC(1)
\item CRC-\/8 calculated over first 23 bytes, stored in byte 24
\end{DoxyItemize}
\end{DoxyEnumerate}

Network Configuration Structure\+:
\begin{DoxyItemize}
\item MAC Address\+: 6-\/byte hardware address (derived from serial number)
\item IP Address\+: 4-\/byte IPv4 address (default or DHCP-\/assigned)
\item Subnet Mask\+: 4-\/byte network mask
\item Gateway\+: 4-\/byte default gateway address
\item DNS Server\+: 4-\/byte domain name server address
\item DHCP Enable\+: 1-\/byte flag (0=static, 1=DHCP)
\item CRC-\/8\+: 1-\/byte checksum for integrity verification
\end{DoxyItemize}

CRC-\/8 Validation\+:
\begin{DoxyItemize}
\item Polynomial\+: 0x07 (via \doxylink{device__identity_8c_aae57a92db26b8a63b7584fd2f3407077}{calculate\+\_\+crc8()})
\item Calculated over all data bytes before CRC field
\item Read operations fail on CRC mismatch
\item Failed reads trigger fallback to defaults
\item Successful reads trigger MAC repair check
\end{DoxyItemize}

MAC Address Repair\+:
\begin{DoxyItemize}
\item Automatic detection of corrupted MAC values
\item Checks prefix matches ENERGIS\+\_\+\+MAC\+\_\+\+PREFIX
\item Detects invalid suffix patterns (all zeros, all 0x\+FF)
\item Enforces serial-\/derived MAC on provisioned devices
\item Repaired MAC persisted immediately to EEPROM
\item Repair events logged as ERR\+\_\+\+SEV\+\_\+\+WARNING
\end{DoxyItemize}

Load Operation Flow\+:
\begin{DoxyEnumerate}
\item \doxylink{group__storage07_ga37c460b3ea58fd130cea86904b06f7b1}{Load\+User\+Network\+Config()} reads from EEPROM with CRC validation
\item If CRC valid\+: a. Check MAC address with \doxylink{group__storage08_ga09214f477c63d362bbc5146830c33d8c}{Energis\+\_\+\+Repair\+Mac()} b. If MAC corrupted, regenerate from serial and persist c. Return validated/repaired configuration
\item If CRC invalid or EEPROM empty\+: a. Load DEFAULT\+\_\+\+NETWORK structure b. Generate MAC from Device\+Identity serial c. Persist defaults to EEPROM d. Return default configuration
\end{DoxyEnumerate}

Thread Safety\+:
\begin{DoxyItemize}
\item All read/write functions require eeprom\+Mtx held by caller
\item \doxylink{group__storage07_ga37c460b3ea58fd130cea86904b06f7b1}{Load\+User\+Network\+Config()} manages mutex internally
\item Prevents concurrent access corruption
\item Ensures atomic read-\/modify-\/write for MAC repair
\end{DoxyItemize}

Integration Points\+:
\begin{DoxyItemize}
\item Device\+Identity\+: Provides serial number for MAC generation
\item storage\+\_\+common\+: CRC-\/8 calculation and MAC repair functions
\item Storage\+Task\+: Provides DEFAULT\+\_\+\+NETWORK and eeprom\+Mtx
\item Net\+Task\+: Consumes loaded network configuration
\item W5500 Ethernet\+: MAC address programming
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item Bounds checking on all buffer operations
\item CRC mismatch logged as ERR\+\_\+\+SEV\+\_\+\+ERROR
\item MAC repair logged as ERR\+\_\+\+SEV\+\_\+\+WARNING
\item Failed reads fall back to safe defaults
\item Error codes enqueued to event log
\end{DoxyItemize}

API Layers\+:
\begin{DoxyItemize}
\item Raw APIs\+: Direct EEPROM access without CRC (for legacy/debug)
\item CRC APIs\+: Recommended for production use with integrity checking
\item Load API\+: High-\/level with defaults and automatic repair
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Always prefer CRC-\/verified APIs for production code. 

\doxylink{group__storage07_ga37c460b3ea58fd130cea86904b06f7b1}{Load\+User\+Network\+Config()} is the recommended high-\/level interface. 

Raw APIs provided for legacy compatibility and debug access. 

MAC address uniqueness depends on unique device serial numbers.
\end{DoxyNote}

Load network configuration from EEPROM with automatic fallback and MAC repair. 

High-\/level interface for loading network configuration. Attempts EEPROM read with CRC validation. On success, performs automatic MAC address repair if needed. On failure, returns default configuration with MAC derived from device serial number. Manages eeprom\+Mtx internally for thread-\/safe operation.

Operation Flow\+:
\begin{DoxyEnumerate}
\item Acquire eeprom\+Mtx for thread-\/safe access
\item Call \doxylink{group__storage07_gaef5b120a12ff3e275706067ea3cf7e46}{EEPROM\+\_\+\+Read\+User\+Network\+With\+Checksum()} to read with CRC validation
\item If CRC valid\+: a. Call \doxylink{group__storage08_ga09214f477c63d362bbc5146830c33d8c}{Energis\+\_\+\+Repair\+Mac()} to check MAC integrity b. If MAC repaired, persist corrected config to EEPROM c. Log repair event as ERR\+\_\+\+SEV\+\_\+\+WARNING d. Return validated/repaired configuration
\item If CRC invalid or EEPROM empty\+: a. Load DEFAULT\+\_\+\+NETWORK structure from Storage\+Task b. Call \doxylink{group__storage08_gad5fac108da78e4ddeb0cf70283a0a5dc}{Energis\+\_\+\+Fill\+Mac\+From\+Serial()} to generate MAC from serial c. Persist defaults to EEPROM for future boots d. Log fallback event as ERR\+\_\+\+SEV\+\_\+\+WARNING e. Return default configuration
\item Release eeprom\+Mtx
\end{DoxyEnumerate}

MAC Repair Conditions\+:
\begin{DoxyItemize}
\item Wrong vendor prefix (not ENERGIS\+\_\+\+MAC\+\_\+\+PREFIX)
\item Invalid suffix patterns (all zeros or all 0x\+FF)
\item MAC mismatch on provisioned devices (enforces serial-\/derived MAC)
\end{DoxyItemize}

Default Configuration\+:
\begin{DoxyItemize}
\item Network settings from DEFAULT\+\_\+\+NETWORK constant
\item MAC address generated from Device\+Identity serial number
\item Safe fallback for first boot or EEPROM corruption
\end{DoxyItemize}
