\doxysubsubsubsection{Detailed Description}
Device name, location, and display settings with CRC-\/8 validation. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/14
\end{DoxyDate}
This module manages user-\/configurable preferences stored in EEPROM with CRC-\/8 data integrity protection. Includes device identification strings and display settings with automatic fallback to defaults on corruption.

Key Features\+:
\begin{DoxyItemize}
\item Device name customization (up to 31 characters)
\item Physical location string (up to 31 characters)
\item Temperature unit selection (Celsius/\+Fahrenheit)
\item CRC-\/8 validation for data integrity
\item Automatic fallback to built-\/in defaults
\item Split-\/write protection for EEPROM page boundaries
\end{DoxyItemize}

EEPROM Memory Layout (EEPROM\+\_\+\+USER\+\_\+\+PREF\+\_\+\+START, 66 bytes total)\+:
\begin{DoxyItemize}
\item Offset 0-\/31\+: Device name string (null-\/terminated)
\item Offset 32-\/63\+: Location string (null-\/terminated)
\item Offset 64\+: Temperature unit (0=Celsius, 1=Fahrenheit)
\item Offset 65\+: CRC-\/8 checksum
\end{DoxyItemize}

Data Structure\+:
\begin{DoxyItemize}
\item Device Name\+: 32-\/byte field for user-\/defined device name
\begin{DoxyItemize}
\item Default\+: "{}\+ENERGIS PDU"{}
\item Used in SNMP sys\+Name and web interface
\item Automatically null-\/terminated
\end{DoxyItemize}
\item Location\+: 32-\/byte field for physical location
\begin{DoxyItemize}
\item Default\+: "{}\+Unknown"{}
\item Used in SNMP sys\+Location and web interface
\item Automatically null-\/terminated
\end{DoxyItemize}
\item Temperature Unit\+: 1-\/byte enum
\begin{DoxyItemize}
\item 0 = Celsius (default)
\item 1 = Fahrenheit
\item Applied to web interface and SNMP OID output
\end{DoxyItemize}
\end{DoxyItemize}

CRC-\/8 Validation\+:
\begin{DoxyItemize}
\item Polynomial\+: 0x07 (via \doxylink{device__identity_8c_aae57a92db26b8a63b7584fd2f3407077}{calculate\+\_\+crc8()})
\item Calculated over first 65 bytes (name + location + temp\+\_\+unit)
\item Stored in byte 66
\item Read operations fail on CRC mismatch
\item Failed reads trigger fallback to defaults
\end{DoxyItemize}

Split-\/\+Write Protection\+:
\begin{DoxyItemize}
\item \doxylink{group__storage11_gaffd968de2dd26c2a571f3057dc72f2dc}{EEPROM\+\_\+\+Write\+User\+Prefs\+With\+Checksum()} uses split writes
\item Prevents corruption from writes spanning page boundaries
\item First 64 bytes (strings)\+: single 64-\/byte write
\item Last 2 bytes (temp\+\_\+unit + CRC)\+: separate 2-\/byte write
\item CAT24\+C256 has 64-\/byte page size requiring alignment
\end{DoxyItemize}

Load Operation Flow\+:
\begin{DoxyEnumerate}
\item \doxylink{group__storage11_gada0abcfc99e366656030e908187d6d6d}{Load\+User\+Preferences()} reads from EEPROM with CRC validation
\item If CRC valid\+: a. Return validated configuration b. Ensure strings are null-\/terminated
\item If CRC invalid or EEPROM empty\+: a. Load DEFAULT\+\_\+\+USER\+\_\+\+PREFS structure b. Persist defaults to EEPROM for future boots c. Return default configuration
\end{DoxyEnumerate}

Default Configuration\+:
\begin{DoxyItemize}
\item Device name\+: "{}\+ENERGIS PDU"{}
\item Location\+: "{}\+Unknown"{}
\item Temperature unit\+: Celsius (0)
\item Used on first boot or EEPROM corruption
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item All read/write functions require eeprom\+Mtx held by caller
\item \doxylink{group__storage11_gada0abcfc99e366656030e908187d6d6d}{Load\+User\+Preferences()} manages mutex internally
\item Prevents concurrent access corruption
\end{DoxyItemize}

Integration Points\+:
\begin{DoxyItemize}
\item storage\+\_\+common\+: CRC-\/8 calculation
\item Storage\+Task\+: Provides DEFAULT\+\_\+\+USER\+\_\+\+PREFS and eeprom\+Mtx
\item Net\+Task\+: Reads device name for SNMP sys\+Name
\item Web interface\+: Displays device name and location
\item Meter\+Task\+: Applies temperature unit to sensor readings
\end{DoxyItemize}

API Layers\+:
\begin{DoxyItemize}
\item Raw APIs\+: Direct EEPROM access without CRC (for legacy/debug)
\item CRC APIs\+: Recommended for production use with integrity checking
\item Load API\+: High-\/level with defaults and automatic fallback
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Always prefer CRC-\/verified APIs for production code. 

\doxylink{group__storage11_gada0abcfc99e366656030e908187d6d6d}{Load\+User\+Preferences()} is the recommended high-\/level interface. 

Strings are always null-\/terminated on read operations. 

Split writes required to respect CAT24\+C256 page boundaries.
\end{DoxyNote}

High-\/level interface for loading user preferences. Attempts EEPROM read with CRC validation. On success, returns validated configuration. On failure, returns default configuration and persists defaults to EEPROM. Manages eeprom\+Mtx internally for thread-\/safe operation.

Operation Flow\+:
\begin{DoxyEnumerate}
\item Acquire eeprom\+Mtx for thread-\/safe access
\item Call \doxylink{group__storage11_ga708039b6b7c8a2535429849aaf0bef39}{EEPROM\+\_\+\+Read\+User\+Prefs\+With\+Checksum()} to read with CRC validation
\item If CRC valid\+: a. Return validated preferences
\item If CRC invalid or EEPROM empty\+: a. Load DEFAULT\+\_\+\+USER\+\_\+\+PREFS structure from Storage\+Task b. Persist defaults to EEPROM for future boots c. Log fallback event as ERR\+\_\+\+SEV\+\_\+\+WARNING d. Return default preferences
\item Release eeprom\+Mtx
\end{DoxyEnumerate}

Default Configuration\+:
\begin{DoxyItemize}
\item Device name\+: "{}\+ENERGIS PDU"{}
\item Location\+: "{}\+Unknown"{}
\item Temperature unit\+: Celsius (0)
\item Safe fallback for first boot or EEPROM corruption
\end{DoxyItemize}

\begin{DoxyReturn}{Returns}
\doxylink{structuser_pref_info}{user\+Pref\+Info} structure containing valid user preferences. Always returns valid data, never fails.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
This is the recommended high-\/level API for loading user preferences. 

Manages eeprom\+Mtx internally; caller should NOT hold mutex. 

Always returns valid configuration via fallback to defaults. 

Default configs automatically persisted to EEPROM. 

Called by web interface and SNMP handlers during initialization.
\end{DoxyNote}
