RTOS-\/safe driver providing power measurement via HLW8032 ICs.

Features\+:
\begin{DoxyItemize}
\item Thread-\/safe UART access via Free\+RTOS mutex
\item Hardware v1.\+0.\+0 pin swap compensation
\item Per-\/channel calibration from EEPROM
\item Cached measurements with uptime tracking
\item Queue-\/based logging (no direct UART printf)
\end{DoxyItemize}

Architecture\+:
\begin{DoxyItemize}
\item Meter\+Task is the sole owner of this driver
\item All blocking operations use v\+Task\+Delay() for RTOS cooperation
\item Multiplexer control delegates to MCP23017 driver
\item No ISRs -\/ pure task-\/based polling
\end{DoxyItemize}
