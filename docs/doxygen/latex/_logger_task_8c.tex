Main logger task function. 

Continuously receives log messages from the queue and outputs them to USB-\/\+CDC (stdout). Implements heartbeat monitoring and maintains responsiveness to the health watchdog even when no messages are pending.

Operation\+:
\begin{DoxyItemize}
\item Initializes USB-\/\+CDC on first run
\item Waits 1 second for USB enumeration
\item Polls queue with 50ms timeout to maintain watchdog responsiveness
\item Outputs received messages immediately to stdout
\item Sends periodic heartbeats to health monitor
\end{DoxyItemize}
