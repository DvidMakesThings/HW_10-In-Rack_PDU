\doxysubsubsection*{User Network Configuration Block}
Network parameters with CRC-\/8 validation and automatic MAC repair.

Stores complete network configuration including MAC address, IPv4 settings, and DHCP mode. Protected by CRC-\/8 checksum with automatic MAC address repair on corruption.

Structure Layout (32 bytes total)\+:
\begin{DoxyItemize}
\item Offset 0-\/5\+: MAC address (6 bytes)
\item Offset 6-\/9\+: IPv4 address (4 bytes)
\item Offset 10-\/13\+: Subnet mask (4 bytes)
\item Offset 14-\/17\+: Default gateway (4 bytes)
\item Offset 18-\/21\+: DNS server (4 bytes)
\item Offset 22\+: DHCP enable (1 byte, 0=static 1=DHCP)
\item Offset 23\+: CRC-\/8 checksum (1 byte)
\item Offset 24-\/31\+: Unused (reserved for expansion)
\end{DoxyItemize}

MAC Address Management\+:
\begin{DoxyItemize}
\item Format\+: ENERGIS\+\_\+\+MAC\+\_\+\+PREFIX (3 bytes) + Serial hash (3 bytes)
\item Derived from device serial number via FNV-\/1a hash
\item Automatically repaired if corruption detected on boot
\item Repair checks\+: Invalid prefix, all-\/zero/0x\+FF suffix, serial mismatch
\end{DoxyItemize}

Default Configuration\+:
\begin{DoxyItemize}
\item IP\+: 192.\+168.\+1.\+100
\item Subnet\+: 255.\+255.\+255.\+0
\item Gateway\+: 192.\+168.\+1.\+1
\item DNS\+: 8.\+8.\+8.\+8
\item DHCP\+: Disabled (static IP)
\item MAC\+: Derived from serial number
\end{DoxyItemize}

CRC Validation\+:
\begin{DoxyItemize}
\item Polynomial\+: 0x07 (via calculate\+\_\+crc8)
\item Input\+: Bytes 0-\/22 (MAC through DHCP flag)
\item Stored at offset 23
\item Failed CRC triggers fallback to defaults
\end{DoxyItemize}

Access Pattern\+:
\begin{DoxyItemize}
\item Written\+: Web interface, SNMP, console commands, first boot
\item Read\+: Boot time (Net\+Task initialization), web interface
\item Frequency\+: Occasional user configuration changes
