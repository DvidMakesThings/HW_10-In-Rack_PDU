\doxysubsection{Detailed Description}
\begin{DoxyAuthor}{Author}
Dvid\+Makes\+Things -\/ David Sipos
\end{DoxyAuthor}
\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/06
\end{DoxyDate}
Implements a Free\+RTOS-\/based health monitoring task that manages the hardware watchdog, tracks heartbeats from registered tasks, logs diagnostics, and records long blocking events for post-\/mortem analysis. Key behavior\+:
\begin{DoxyItemize}
\item Graceful ARMING\+: watchdog is enabled only after a warmup period and after at least one heartbeat from each registered task (or warmup timeout).
\item LIVENESS WINDOW\+: each task must heartbeat at least once within HEALTH\+\_\+\+SILENCE\+\_\+\+MS; otherwise the watchdog is NOT fed.
\item DIAGNOSTICS\+: prints stack high-\/water marks and free heap periodically, and keeps a small ring of "{}blocked"{} events for post-\/mortem.
\end{DoxyItemize}

Integration\+: 1) Call Health\+\_\+\+Register\+Task(id, handle, "{}name"{}) after x\+Task\+Create for each task. 2) Call \doxylink{group__tasks03_gaaa57b8a364b1e80fdbcbd231b80ee70d}{Health\+Task\+\_\+\+Start()} once everything is created (at end of Init\+Task). 3) Inside each task loop, call Health\+\_\+\+Heartbeat(\+HEALTH\+\_\+\+ID\+\_\+xxx) once per loop. 4) Optionally call Health\+\_\+\+Record\+Blocked("{}tag"{}, waited\+\_\+ms) on long waits.

\begin{DoxyNote}{Note}
Do NOT arm another watchdog elsewhere. Let Health\+Task manage it. You can adjust HEALTH\+\_\+\+WARMUP\+\_\+\+MS and HEALTH\+\_\+\+SILENCE\+\_\+\+MS below. @project ENERGIS -\/ The Managed PDU Project for 10-\/Inch Rack @github \href{https://github.com/DvidMakesThings/HW_10-In-Rack_PDU}{\texttt{https\+://github.\+com/\+Dvid\+Makes\+Things/\+HW\+\_\+10-\/\+In-\/\+Rack\+\_\+\+PDU}} 
\end{DoxyNote}
