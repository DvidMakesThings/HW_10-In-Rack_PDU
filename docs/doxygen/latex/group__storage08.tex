\doxysubsubsubsection{Detailed Description}
Shared utility functions for EEPROM data integrity and MAC address management. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/14
\end{DoxyDate}
This module provides common utility functions used across all storage submodules for data integrity verification and network hardware addressing. It serves as the foundation layer for EEPROM configuration management.

Key Features\+:
\begin{DoxyItemize}
\item CRC-\/8 checksum calculation for data integrity verification
\item MAC address derivation from device serial number via FNV-\/1a hash
\item MAC address validation and automatic repair for corrupted values
\item Integration with Device\+Identity module for provisioned device support
\end{DoxyItemize}

CRC-\/8 Algorithm\+:
\begin{DoxyItemize}
\item Polynomial\+: 0x07
\item Initial value\+: 0x00
\item Used by\+: network config, user preferences, device identity
\item Detects single-\/bit errors and most multi-\/bit errors
\item Fast computation suitable for embedded systems
\end{DoxyItemize}

MAC Address Management\+:
\begin{DoxyItemize}
\item Format\+: ENERGIS\+\_\+\+MAC\+\_\+\+PREFIX (3 bytes) + FNV-\/1a hash (3 bytes)
\item Prefix\+: Fixed vendor-\/specific OUI for ENERGIS devices
\item Suffix\+: Derived from device serial number for uniqueness
\item Hash algorithm\+: FNV-\/1a provides good distribution
\item Validation\+: Detects corrupted prefix or invalid suffix patterns
\item Auto-\/repair\+: Regenerates MAC from serial when corruption detected
\end{DoxyItemize}

Provisioning Integration\+:
\begin{DoxyItemize}
\item Unprovisioned devices use placeholder serial number
\item After provisioning, MAC automatically updated to match new serial
\item \doxylink{group__storage08_ga09214f477c63d362bbc5146830c33d8c}{Energis\+\_\+\+Repair\+Mac()} enforces serial-\/\+MAC consistency
\item Ensures unique MAC addresses across production devices
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item \doxylink{group__storage08_gaae57a92db26b8a63b7584fd2f3407077}{calculate\+\_\+crc8()} called by submodules before EEPROM writes
\item CRC verified on reads to detect corruption
\item \doxylink{group__storage08_gad5fac108da78e4ddeb0cf70283a0a5dc}{Energis\+\_\+\+Fill\+Mac\+From\+Serial()} populates MAC in network config
\item \doxylink{group__storage08_ga09214f477c63d362bbc5146830c33d8c}{Energis\+\_\+\+Repair\+Mac()} called on boot to fix any corruption
\end{DoxyEnumerate}

Integration Points\+:
\begin{DoxyItemize}
\item Device\+Identity\+: Provides serial number and provisioning status
\item Network submodule\+: Uses MAC functions for Ethernet configuration
\item All storage submodules\+: Use CRC-\/8 for data integrity
\end{DoxyItemize}

\begin{DoxyNote}{Note}
CRC-\/8 provides error detection but not correction; corrupted data must be reloaded. 

MAC address uniqueness depends on unique device serial numbers. 

\doxylink{group__storage08_ga09214f477c63d362bbc5146830c33d8c}{Energis\+\_\+\+Repair\+Mac()} modifies \doxylink{structnetwork_info}{network\+Info} structure in place.
\end{DoxyNote}

Calculate CRC-\/8 checksum for data integrity verification. 

Computes CRC-\/8 checksum using polynomial 0x07 with initial value 0x00. Used by storage submodules to detect data corruption in EEPROM. The CRC is typically stored alongside the data and verified on read operations.

Algorithm Properties\+:
\begin{DoxyItemize}
\item Detects all single-\/bit errors
\item Detects most multi-\/bit errors
\item Fast computation suitable for embedded systems
\item 8-\/bit output suitable for constrained EEPROM space
\end{DoxyItemize}

Validate and repair corrupted MAC address. 

Checks MAC address for common corruption patterns and repairs if invalid. Detects wrong vendor prefix, all-\/zero suffix, all-\/0x\+FF suffix, and serial-\/\+MAC mismatch on provisioned devices. Repairs by regenerating MAC from current device serial number.

Validation Checks\+:
\begin{DoxyEnumerate}
\item Prefix matches ENERGIS\+\_\+\+MAC\+\_\+\+PREFIX (vendor OUI)
\item Suffix not all zeros (invalid EEPROM initialization)
\item Suffix not all 0x\+FF (erased EEPROM pattern)
\item MAC matches serial-\/derived value (post-\/provisioning enforcement)
\end{DoxyEnumerate}

Repair Action\+:
\begin{DoxyItemize}
\item Calls \doxylink{group__storage03_ga461c49efb137c6fcc9871867b974c326}{Device\+Identity\+\_\+\+Fill\+Mac()} to regenerate from current serial
\item Overwrites corrupted MAC in \doxylink{structnetwork_info}{network\+Info} structure
\item Ensures consistency between serial number and MAC address
\end{DoxyItemize}
