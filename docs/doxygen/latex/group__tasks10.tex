\doxysubsubsection{Detailed Description}
Persistent configuration manager with CAT24\+C256 EEPROM and queue-\/based access. 

\begin{DoxyVersion}{Version}
3.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/01-\/01
\end{DoxyDate}
This module implements a Free\+RTOS task for managing all persistent configuration data stored in the CAT24\+C256 EEPROM. It provides the exclusive interface to EEPROM hardware, maintains RAM caches for frequently-\/accessed data, and implements write-\/debouncing to extend EEPROM lifetime.

Architecture\+:
\begin{DoxyItemize}
\item Single-\/owner model\+: Storage\+Task has exclusive access to CAT24\+C256 EEPROM
\item Queue-\/based request processing\+: all external access via q\+\_\+cfg message queue
\item RAM caching\+: critical config mirrored in RAM for fast access without I2C
\item Write debouncing\+: 2-\/second idle period before committing pending writes
\item Modular design\+: each EEPROM section managed by dedicated submodule
\item Thread-\/safe\+: mutex-\/protected EEPROM access, event-\/based readiness signaling
\end{DoxyItemize}

Key Features\+:
\begin{DoxyItemize}
\item Network configuration storage (IP, subnet, gateway, DNS, MAC, DHCP mode)
\item User preferences (device name, location, display settings)
\item Relay state persistence (startup configuration, user-\/defined presets)
\item Channel labels (8×64-\/character custom names, RAM cached)
\item Sensor calibration data (HLW8032 voltage/current/power offsets per channel)
\item Event logging (error and warning ring buffers with timestamps)
\item Energy monitoring (historical energy consumption logs)
\item Factory defaults system (first-\/boot initialization, reset capability)
\item Device identity (serial number, region, MAC address derivation)
\end{DoxyItemize}

Submodules (in storage\+\_\+submodule/)\+:
\begin{DoxyItemize}
\item storage\+\_\+common\+: CRC-\/16 computation, MAC address utilities, shared types
\item factory\+\_\+defaults\+: First-\/boot detection and default configuration initialization
\item user\+\_\+output\+: Relay state persistence with preset system (5 presets + startup)
\item network\+: Network configuration with CRC validation and fallback defaults
\item calibration\+: Per-\/channel HLW8032 calibration coefficients
\item energy\+\_\+monitor\+: Ring buffer for historical energy consumption tracking
\item event\+\_\+log\+: Dual ring buffers for error and warning event history
\item user\+\_\+prefs\+: Device name, location, and display preference storage
\item channel\+\_\+labels\+: User-\/defined channel names with RAM cache and lazy loading
\end{DoxyItemize}

Message Queue Interface\+:
\begin{DoxyItemize}
\item Asynchronous requests posted to q\+\_\+cfg queue from any task
\item Synchronous completion via optional semaphore in message structure
\item Command types cover read, write, commit, clear, dump operations
\item Output pointers allow direct result delivery to requester
\end{DoxyItemize}

Write Debouncing\+:
\begin{DoxyItemize}
\item Dirty flags track sections with pending writes
\item Timer resets on each modification (2-\/second idle requirement)
\item Automatic commit when idle period expires
\item Manual commit available via STORAGE\+\_\+\+CMD\+\_\+\+COMMIT
\item Reduces EEPROM wear during configuration changes
\end{DoxyItemize}

Configuration Readiness\+:
\begin{DoxyItemize}
\item CFG\+\_\+\+READY\+\_\+\+BIT event flag signals boot configuration loaded
\item Other tasks wait on \doxylink{group__tasks10_gafeb6e0067e67c68af21f0eeae1d1279a}{storage\+\_\+wait\+\_\+ready()} before accessing config
\item Deterministic boot sequencing ensures config availability
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item Deferred error/warning queues prevent logging deadlocks
\item EEPROM write failures logged with diagnostic codes
\item CRC validation detects corruption and triggers fallback defaults
\item I2C errors logged and retried with exponential backoff
\end{DoxyItemize}

EEPROM Memory Layout\+:
\begin{DoxyItemize}
\item Organized into fixed-\/offset sections per \doxylink{_e_e_p_r_o_m___memory_map_8h}{EEPROM\+\_\+\+Memory\+Map.\+h}
\item Each section has dedicated submodule managing layout and CRC
\item Factory marker region identifies virgin vs programmed devices
\item Ring buffers use head/tail pointers for circular operation
\end{DoxyItemize}

Integration Points\+:
\begin{DoxyItemize}
\item Net\+Task\+: loads network configuration at boot
\item Switch\+Task\+: applies relay states from startup preset
\item Meter\+Task\+: loads sensor calibration coefficients
\item HTTP/\+SNMP handlers\+: read device name, labels, config for display
\item Console\+Task\+: provides configuration commands and diagnostics
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Only Storage\+Task should access CAT24\+C256 hardware; all others use queue API. 

Configuration changes auto-\/commit after 2-\/second idle period. 

EEPROM has \texorpdfstring{$\sim$}{\string~}1 million write cycle endurance; debouncing extends lifetime. 

RAM cache reduces I2C traffic for frequently-\/read configuration.
\end{DoxyNote}
