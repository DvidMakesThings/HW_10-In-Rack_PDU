\doxysubsubsubsection{Detailed Description}
HLW8032 power meter calibration per channel. 

\begin{DoxyVersion}{Version}
1.\+2 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/15
\end{DoxyDate}
This module manages calibration data for two sensor subsystems\+: HLW8032 power meters (8 channels) and RP2040 internal temperature sensor. Provides EEPROM persistence, calibration computation helpers, and runtime application to Meter\+Task.

Key Features\+:
\begin{DoxyItemize}
\item Per-\/channel HLW8032 calibration with voltage/current factors
\item RP2040 temperature sensor calibration (1-\/point or 2-\/point)
\item EEPROM persistence with bounds checking
\item Calibration computation helpers for temperature
\item Runtime application to Meter\+Task measurement path
\end{DoxyItemize}

HLW8032 Calibration\+:
\begin{DoxyItemize}
\item 8 independent channels with individual calibration records
\item Each channel stores\+:
\begin{DoxyItemize}
\item Voltage factor (HLW8032\+\_\+\+VF default\+: 0.\+596)
\item Current factor (HLW8032\+\_\+\+CF default\+: 14.\+871)
\item Voltage offset (zero-\/point compensation)
\item Current offset (zero-\/point compensation)
\item Resistor divider values (R1, R2, shunt)
\item Calibration status flags
\end{DoxyItemize}
\item Channel calibration stored as \doxylink{structhlw__calib__t}{hlw\+\_\+calib\+\_\+t} structure
\item EEPROM location\+: EEPROM\+\_\+\+SENSOR\+\_\+\+CAL\+\_\+\+START + (ch \texorpdfstring{$\ast$}{*} sizeof(hlw\+\_\+calib\+\_\+t))
\item Bulk read/write for all channels or individual channel access
\end{DoxyItemize}

Temperature Calibration\+:
\begin{DoxyItemize}
\item RP2040 internal temperature sensor compensation
\item Two calibration modes\+:
\begin{DoxyItemize}
\item TEMP\+\_\+\+CAL\+\_\+\+MODE\+\_\+1\+PT\+: Single-\/point offset calibration
\item TEMP\+\_\+\+CAL\+\_\+\+MODE\+\_\+2\+PT\+: Two-\/point slope + intercept calibration
\end{DoxyItemize}
\item Stored as \doxylink{structtemp__calib__t}{temp\+\_\+calib\+\_\+t} structure with magic/version/\+CRC32
\item Default model\+: V0=0.\+706V@27°C, slope=0.\+001721V/°C
\item EEPROM location\+: EEPROM\+\_\+\+TEMP\+\_\+\+CAL\+\_\+\+START (separate block)
\item Computation functions for deriving calibration from measurements
\end{DoxyItemize}

EEPROM Layout\+:
\begin{DoxyEnumerate}
\item HLW8032 Calibration Block (EEPROM\+\_\+\+SENSOR\+\_\+\+CAL\+\_\+\+START)\+:
\begin{DoxyItemize}
\item Size\+: EEPROM\+\_\+\+SENSOR\+\_\+\+CAL\+\_\+\+SIZE bytes
\item Contents\+: 8 × \doxylink{structhlw__calib__t}{hlw\+\_\+calib\+\_\+t} structures (one per channel)
\item Layout\+: Channel 0 @ offset 0, Channel 1 @ offset sizeof(hlw\+\_\+calib\+\_\+t), etc.
\end{DoxyItemize}
\item Temperature Calibration Block (EEPROM\+\_\+\+TEMP\+\_\+\+CAL\+\_\+\+START)\+:
\begin{DoxyItemize}
\item Size\+: EEPROM\+\_\+\+TEMP\+\_\+\+CAL\+\_\+\+SIZE bytes
\item Contents\+: \doxylink{structtemp__calib__t}{temp\+\_\+calib\+\_\+t} structure with magic/version/\+CRC32
\item Magic\+: \textquotesingle{}TC\textquotesingle{} (0x5443) for validity detection
\item Version\+: TEMP\+\_\+\+CAL\+\_\+\+VERSION (0x0001)
\end{DoxyItemize}
\end{DoxyEnumerate}

Temperature Calibration Workflow\+:
\begin{DoxyEnumerate}
\item Measure ADC raw value at known temperature(s)
\item Call \doxylink{group__storage01_ga73504452f7a1b317e752b7f668694a3d}{Temp\+Calibration\+\_\+\+Compute\+Single\+Point()} or \doxylink{group__storage01_ga655669ab4b049b7ef9bcf70ea3d06ec6}{Temp\+Calibration\+\_\+\+Compute\+Two\+Point()}
\item Write computed record to EEPROM via \doxylink{group__storage01_gabc289be7b0cdbb53e52f48a0a10701ac}{EEPROM\+\_\+\+Write\+Temp\+Calibration()}
\item Apply to Meter\+Task via \doxylink{group__storage01_ga7796a67e219e367ba5424202cff756ae}{Temp\+Calibration\+\_\+\+Apply\+To\+Meter\+Task()}
\item On boot, use \doxylink{group__storage01_ga1a4a0e2917c171c09500b674b6f2911f}{Temp\+Calibration\+\_\+\+Load\+And\+Apply()} for automatic load+apply
\end{DoxyEnumerate}

Single-\/\+Point Calibration\+:
\begin{DoxyItemize}
\item Measures offset only, assumes default slope
\item Requires one known temperature measurement
\item Suitable for reducing ambient temperature error
\item Sets offset so T\+\_\+reported = T\+\_\+actual at calibration point
\end{DoxyItemize}

Two-\/\+Point Calibration\+:
\begin{DoxyItemize}
\item Measures both slope and V0 intercept
\item Requires two temperature measurements (e.\+g., ambient + warmed)
\item Better accuracy across temperature range
\item Compensates for per-\/die slope variation
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item All EEPROM read/write functions require eeprom\+Mtx held by caller
\item Calibration computation functions are reentrant (no EEPROM access)
\item \doxylink{group__storage01_ga7796a67e219e367ba5424202cff756ae}{Temp\+Calibration\+\_\+\+Apply\+To\+Meter\+Task()} sends queue message to Meter\+Task
\item \doxylink{group__storage01_ga1a4a0e2917c171c09500b674b6f2911f}{Temp\+Calibration\+\_\+\+Load\+And\+Apply()} manages mutex internally
\end{DoxyItemize}

Integration Points\+:
\begin{DoxyItemize}
\item Meter\+Task\+: Consumes calibration data for measurements
\item Storage\+Task\+: Provides eeprom\+Mtx for thread-\/safe access
\item factory\+\_\+defaults\+: Writes default calibration on first boot
\item Console commands\+: UART calibration workflow
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item Bounds checking on all EEPROM operations
\item Null pointer checks on all function inputs
\item Invalid channel index rejection
\item Magic/version validation for temperature calibration
\item CRC32 validation (optional, currently not enforced)
\item Error codes logged and enqueued to event log
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Always call EEPROM functions with eeprom\+Mtx held. 

Temperature calibration applies globally, not per-\/channel. 

HLW8032 calibration is per-\/channel and independent. 

Calibration changes do not take effect until applied to Meter\+Task.
\end{DoxyNote}

Load temperature calibration from EEPROM and apply to Meter\+Task. 

Convenience function combining EEPROM read, validation, and Meter\+Task application. Reads calibration record from EEPROM, validates magic/version, and applies to Meter\+Task. If invalid, applies safe defaults. Typical usage during boot sequence.
