\doxysubsection{Detailed Description}
Internal state for the asynchronous HLW8032 auto-\/calibration engine. 

This state is driven cooperatively from normal polling via \doxylink{group__drivers04_gaf9b4059456656d1620a19fa771086a2d}{hlw8032\+\_\+read()}, so calibration runs without blocking any single task or starving the WD.
