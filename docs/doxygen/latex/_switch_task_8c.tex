\doxysubsection{Detailed Description}
\begin{DoxyAuthor}{Author}
Dvid\+Makes\+Things -\/ David Sipos
\end{DoxyAuthor}
\begin{DoxyVersion}{Version}
3.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/14
\end{DoxyDate}
A simple, deterministic implementation for relay control\+:
\begin{DoxyItemize}
\item Single mutex serializes all MCP23017 access
\item Direct read/write calls to MCP driver (no queues)
\item Display LEDs mirror relay states (best-\/effort with short backoff)
\end{DoxyItemize}

Thread-\/safety\+:
\begin{DoxyItemize}
\item All public APIs acquire the Switch\+Task mutex and are blocking.
\item APIs return immediately with detailed codes for callers (see header).
\end{DoxyItemize}
