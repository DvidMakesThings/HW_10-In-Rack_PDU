\doxysubsubsection{Detailed Description}
Centralized logging subsystem with queue-\/based message handling. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/06
\end{DoxyDate}
This module implements a centralized logging system for the PDU firmware using a Free\+RTOS task and message queue architecture. It provides thread-\/safe logging from any task context with optional muting capability for critical sections.

Architecture\+:
\begin{DoxyItemize}
\item Queue-\/based message passing decouples log generation from output
\item Single consumer task (Logger\+Task) handles all USB-\/\+CDC output
\item Non-\/blocking sends prevent logging from blocking application tasks
\item Configurable queue depth and message size
\item Mute functionality for reducing noise during debug operations
\end{DoxyItemize}

Key Features\+:
\begin{DoxyItemize}
\item Thread-\/safe logging from any task or ISR context
\item Printf-\/style formatting with variadic arguments
\item Automatic message truncation to prevent buffer overflows
\item Non-\/blocking queue operations (messages dropped if queue full)
\item Nested mute/unmute support for critical sections
\item Force-\/log capability to bypass mute state
\item Integrated with health monitoring for watchdog supervision
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item Initialize early in boot sequence via Logger\+Task\+\_\+\+Init(true)
\item Use \doxylink{group__tasks05_ga2473a4441580b27bdc14f48e2d2fff8e}{log\+\_\+printf()} from any task for normal logging
\item Use \doxylink{group__tasks05_gafc11bbe1cbc3f91b4eec771974d1cc22}{Logger\+\_\+\+Mute\+Push()}/\+Mute\+Pop() to temporarily suppress logs
\item Use \doxylink{group__tasks05_ga36194a3f790c1e727f3b9ab3c0ab38ba}{log\+\_\+printf\+\_\+force()} to log even when muted
\end{DoxyEnumerate}

Output\+:
\begin{DoxyItemize}
\item All logs directed to USB-\/\+CDC (stdout via stdio\+\_\+init\+\_\+all)
\item 1-\/second delay after init for USB enumeration
\item Immediate console availability for early boot diagnostics
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Logger\+Task should be initialized first in boot sequence to capture all subsequent initialization logs. 

Messages are truncated to LOGGER\+\_\+\+MSG\+\_\+\+MAX bytes if too long. 

Queue full condition silently drops messages (check LOGGER\+\_\+\+QUEUE\+\_\+\+LEN).
\end{DoxyNote}

Suppresses all \doxylink{group__tasks05_ga2473a4441580b27bdc14f48e2d2fff8e}{log\+\_\+printf()} output by incrementing an internal mute depth counter. Useful for reducing log noise during intensive debug operations or repetitive tasks. Supports nesting\+: each Mute\+Push() must be matched by a Mute\+Pop().

\begin{DoxyNote}{Note}

Does not affect \doxylink{group__tasks05_ga36194a3f790c1e727f3b9ab3c0ab38ba}{log\+\_\+printf\+\_\+force()} which always outputs. 

Mute state is global; affects all tasks calling \doxylink{group__tasks05_ga2473a4441580b27bdc14f48e2d2fff8e}{log\+\_\+printf()}.

Initialize and start the logger task. 

Creates the Logger\+Task Free\+RTOS task and message queue for centralized logging. Should be called first in the boot sequence to capture all initialization logs from subsequent subsystems.

Initialization Sequence\+:
\begin{DoxyEnumerate}
\item Creates log message queue (LOGGER\+\_\+\+QUEUE\+\_\+\+LEN deep)
\item Spawns Logger\+Task with configured priority and stack size
\item Task initializes USB-\/\+CDC and begins processing queued messages
\end{DoxyEnumerate}


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em enable} & Set true to initialize and start task, false to skip initialization deterministically without side effects.\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
pd\+PASS on successful initialization or when skipped (enable=false). 

pd\+FAIL if initialization fails (queue creation, task creation).
\end{DoxyReturn}
\begin{DoxyNote}{Note}
Call before all other tasks in boot sequence (step 1/6). 

Idempotent\+: safe to call multiple times, creates resources only once. 

Logs error codes to error logger on failure (if error logger available).
\end{DoxyNote}
