\doxysubsubsubsection*{System Info Block}
Firmware version identification and system metadata storage.

Stores the firmware version string at the beginning of EEPROM for easy identification. The version string is read from SWVERSION compile-\/time constant and written during factory defaults initialization. Used for firmware update validation and diagnostics.

\doxysubsubsubsection*{Device Identity Block}
Unique device identification and region configuration storage.

Stores device-\/specific parameters that uniquely identify each PDU unit and determine its operational region (EU/\+US). This block resides within the system info region but is managed separately via UART provisioning commands.

Structure Layout (19 bytes total)\+:
\begin{DoxyItemize}
\item Offset 0x00\+: Serial number (16 bytes, null-\/terminated string)
\item Offset 0x10\+: Region code (1 byte, DEVICE\+\_\+\+REGION\+\_\+\+EU or DEVICE\+\_\+\+REGION\+\_\+\+US)
\item Offset 0x11\+: CRC-\/8 checksum (1 byte, validates serial + region)
\item Offset 0x12\+: Reserved padding (1 byte, for alignment)
\end{DoxyItemize}

Serial Number Format\+:
\begin{DoxyItemize}
\item Up to 15 ASCII characters + null terminator
\item Typically\+: "{}\+ENR"{} + year + production sequence
\item Example\+: "{}\+ENR2025\+A001234"{}
\item Must be unique per device for MAC address derivation
\end{DoxyItemize}

Region Codes\+:
\begin{DoxyItemize}
\item DEVICE\+\_\+\+REGION\+\_\+\+EU (0x45, \textquotesingle{}E\textquotesingle{})\+: 10A current limit (IEC/\+ENEC)
\item DEVICE\+\_\+\+REGION\+\_\+\+US (0x55, \textquotesingle{}U\textquotesingle{})\+: 15A current limit (UL/\+CSA)
\item DEVICE\+\_\+\+REGION\+\_\+\+UNKNOWN (0x00)\+: Unprovisioned device
\end{DoxyItemize}

Provisioning Workflow\+:
\begin{DoxyEnumerate}
\item Device ships with placeholder "{}\+UNPROVISIONED"{} serial
\item Factory uses UART commands to unlock provisioning window
\item Serial number and region written via PROV commands
\item CRC-\/8 calculated and stored for validation
\item MAC address automatically derived from new serial
\end{DoxyEnumerate}

CRC Validation\+:
\begin{DoxyItemize}
\item Polynomial\+: 0x07 (via calculate\+\_\+crc8)
\item Input\+: Serial number (16 bytes) + Region (1 byte)
\item Stored at offset 0x11
\item Validated on boot and before MAC generation
\end{DoxyItemize}

Integration\+:

\item MAC address generation\+: Uses FNV-\/1a hash of serial number
\item Overcurrent protection\+: Region determines current limit
\item Web interface\+: Displays serial number for identification
\item SNMP\+: Serial exposed via custom OID

\doxysubsubsubsection*{User Output Presets Block}
User-\/configurable relay configuration presets with apply-\/on-\/startup feature.

Allows users to save up to 5 named relay configurations for quick recall. One preset can be designated to apply automatically on device startup. Includes header with magic value and CRC16 for data integrity.

Structure Layout (256 bytes total)\+:
\begin{DoxyItemize}
\item Header (4 bytes)\+:
\begin{DoxyItemize}
\item Magic byte (0x\+C5)\+: Data validity marker
\item Startup preset ID (0-\/4 or 0x\+FF for none)
\item Reserved (2 bytes)\+: Future expansion
\end{DoxyItemize}
\item Presets array (140 bytes = 5 × 28 bytes)\+:
\begin{DoxyItemize}
\item Each preset\+: Name (26 bytes) + Relay mask (1 byte) + Valid flag (1 byte)
\end{DoxyItemize}
\item CRC16 (2 bytes)\+: Checksum over header + presets (144 bytes)
\end{DoxyItemize}

Preset Structure (28 bytes each)\+:
\begin{DoxyItemize}
\item Name\+: 25-\/character null-\/terminated string
\item Null terminator\+: Byte 26
\item Relay mask\+: 8-\/bit mask (bit N = channel N state, 1=ON 0=OFF)
\item Valid flag\+: 0x\+A5 if preset used, else empty slot
\end{DoxyItemize}

Apply-\/on-\/\+Startup Feature\+:
\begin{DoxyItemize}
\item Startup preset ID specifies which preset to apply after boot
\item Value 0-\/4\+: Apply corresponding preset
\item Value 0x\+FF\+: No automatic application (use last saved states)
\item Applied before normal operation begins
\end{DoxyItemize}

Access Pattern\+:
\begin{DoxyItemize}
\item Written\+: Web interface preset save/delete, console commands
\item Read\+: Boot time (apply-\/on-\/startup), web interface preset list
\item Frequency\+: Occasional user configuration changes

\doxysubsubsection{Detailed Description}
EEPROM Memory Layout and Data Structures. 

\begin{DoxyVersion}{Version}
2.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/14
\end{DoxyDate}
This file serves as the single authoritative source for all EEPROM memory layout definitions, address assignments, and data structures. It provides a centralized memory map for the CAT24\+C256 32KB I2C EEPROM used in the ENERGIS PDU system.

Key Features\+:
\begin{DoxyItemize}
\item Single source of truth for all EEPROM addresses
\item Hierarchical memory block organization
\item Data structure definitions for all EEPROM regions
\item Constants for network, calibration, and logging parameters
\item Version tracking for memory map evolution
\end{DoxyItemize}

Design Principles\+:
\begin{DoxyItemize}
\item NO MODULE may define EEPROM addresses locally
\item ALL address definitions MUST be in this file
\item Memory regions allocated with gaps for future expansion
\item Page alignment considerations for CAT24\+C256 (64-\/byte pages)
\item Ring buffer regions include pointer storage
\item CRC validation integrated into critical sections
\end{DoxyItemize}

EEPROM Hardware Specifications\+:
\begin{DoxyItemize}
\item Device\+: CAT24\+C256 (Microchip/\+On Semi)
\item Capacity\+: 32KB (32,768 bytes)
\item Address range\+: 0x0000 -\/ 0x7\+FFF
\item Page size\+: 64 bytes
\item Write cycle time\+: 5ms typical
\item Endurance\+: 1,000,000 write cycles
\item Data retention\+: 200 years
\item I2C address\+: Configurable via A0-\/\+A2 pins
\end{DoxyItemize}

Memory Allocation Strategy\+:
\begin{DoxyItemize}
\item Frequently updated regions (event logs, energy) isolated from static config
\item Large gaps between regions allow for growth without relocation
\item Magic value at end prevents accidental detection from blank EEPROM
\item Page-\/aligned writes where possible to maximize CAT24\+C256 efficiency
\item Critical config protected with CRC-\/8 or CRC16
\end{DoxyItemize}

Page Alignment Considerations\+:
\begin{DoxyItemize}
\item CAT24\+C256 has 64-\/byte pages (addresses 0x00-\/0x3F, 0x40-\/0x7F, etc.)
\item Writes spanning page boundary require multiple write cycles
\item Large structures written in page-\/aligned chunks when possible
\item Split-\/write strategy used for user preferences to respect boundaries
\end{DoxyItemize}
