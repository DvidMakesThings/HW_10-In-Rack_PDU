\doxysubsection{Detailed Description}
Network configuration data structure for EEPROM storage. 

Packs all network parameters into a compact structure for EEPROM persistence. Used with CRC-\/8 checksum for data integrity validation. MAC address automatically derived from device serial number and repaired if corrupted.

Fields\+:
\begin{DoxyItemize}
\item mac\+: 6-\/byte hardware address (ENERGIS\+\_\+\+MAC\+\_\+\+PREFIX + FNV-\/1a hash of serial)
\item ip\+: 4-\/byte IPv4 address in network byte order
\item sn\+: 4-\/byte subnet mask in network byte order
\item gw\+: 4-\/byte default gateway address in network byte order
\item dns\+: 4-\/byte DNS server address in network byte order
\item dhcp\+: 1-\/byte flag (0=static IP, 1=DHCP client mode)
\end{DoxyItemize}

Usage\+:
\begin{DoxyItemize}
\item Populated from EEPROM on boot via \doxylink{group__storage07_ga37c460b3ea58fd130cea86904b06f7b1}{Load\+User\+Network\+Config()}
\item Passed to W5500 Ethernet driver for chip configuration
\item Modified via web interface, SNMP, or console commands
\item Persisted to EEPROM with CRC-\/8 via \doxylink{group__storage07_ga3c1fef9aa93f898978387328a8a6e33d}{EEPROM\+\_\+\+Write\+User\+Network\+With\+Checksum()}
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Structure size\+: 23 bytes (before CRC appended). 

CRC-\/8 calculated over entire structure and stored separately. 

MAC address repaired automatically if corrupted. 
\end{DoxyNote}
