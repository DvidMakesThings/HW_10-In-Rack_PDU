\doxysubsubsection{Detailed Description}
Header file for MCP23017 I2C GPIO expander driver. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/16
\end{DoxyDate}
Simplified MCP23017 driver with direct I2C operations. All functions are thread-\/safe via per-\/device mutex.

Design Principles (v2.\+0)\+:
\begin{DoxyItemize}
\item Simple, direct I2C operations with minimal abstraction
\item Per-\/device mutex for thread safety
\item Shadow OLAT registers to prevent torn read-\/modify-\/write
\item Timeout-\/based I2C operations (no infinite blocking)
\item Clear error reporting
\end{DoxyItemize}

Usage\+:
\begin{DoxyEnumerate}
\item Call \doxylink{group__drivers06_ga443377619e6d82e31b58ffc269b64936}{MCP2017\+\_\+\+Init()} once at startup
\item Use \doxylink{group__drivers06_ga6568742c79ce5190216e5185238229ba}{mcp\+\_\+relay()}, \doxylink{group__drivers06_ga7634eca518e2158ba0e636a3f03f3928}{mcp\+\_\+display()}, \doxylink{group__drivers06_gae6acbfdd05b6bdd8877262ce03f77eeb}{mcp\+\_\+selection()} to get device handles
\item Use \doxylink{group__drivers06_ga8b8bc528b75e419262e7663ee669dc31}{mcp\+\_\+write\+\_\+pin()}, \doxylink{group__drivers06_ga2e6de484edec28d8c39620a364ce5b92}{mcp\+\_\+read\+\_\+pin()} for pin operations
\item Use \doxylink{group__drivers06_ga0dfecc1e56ba649b3a89936c6206c9e2}{mcp\+\_\+write\+\_\+mask()} for atomic multi-\/bit operations
\end{DoxyEnumerate}

IMPORTANT\+: For relay control, use Switch\+Task APIs instead of direct MCP calls. This ensures proper serialization and display LED mirroring.
