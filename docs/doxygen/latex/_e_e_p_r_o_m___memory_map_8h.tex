\begin{Indent}\textbf{ Device Identity Block}\par
{\em Unique device identification and region configuration storage.

Stores device-\/specific parameters that uniquely identify each PDU unit and determine its operational region (EU/\+US). This block resides within the system info region but is managed separately via UART provisioning commands.

Structure Layout (19 bytes total)\+:
\begin{DoxyItemize}
\item Offset 0x00\+: Serial number (16 bytes, null-\/terminated string)
\item Offset 0x10\+: Region code (1 byte, DEVICE\+\_\+\+REGION\+\_\+\+EU or DEVICE\+\_\+\+REGION\+\_\+\+US)
\item Offset 0x11\+: CRC-\/8 checksum (1 byte, validates serial + region)
\item Offset 0x12\+: Reserved padding (1 byte, for alignment)
\end{DoxyItemize}

Serial Number Format\+:
\begin{DoxyItemize}
\item Up to 15 ASCII characters + null terminator
\item Typically\+: "{}\+ENR"{} + year + production sequence
\item Example\+: "{}\+ENR2025\+A001234"{}
\item Must be unique per device for MAC address derivation
\end{DoxyItemize}

Region Codes\+:
\begin{DoxyItemize}
\item DEVICE\+\_\+\+REGION\+\_\+\+EU (0x45, \textquotesingle{}E\textquotesingle{})\+: 10A current limit (IEC/\+ENEC)
\item DEVICE\+\_\+\+REGION\+\_\+\+US (0x55, \textquotesingle{}U\textquotesingle{})\+: 15A current limit (UL/\+CSA)
\item DEVICE\+\_\+\+REGION\+\_\+\+UNKNOWN (0x00)\+: Unprovisioned device
\end{DoxyItemize}

Provisioning Workflow\+:
\begin{DoxyEnumerate}
\item Device ships with placeholder "{}\+UNPROVISIONED"{} serial
\item Factory uses UART commands to unlock provisioning window
\item Serial number and region written via PROV commands
\item CRC-\/8 calculated and stored for validation
\item MAC address automatically derived from new serial

\begin{Indent}\textbf{ User Output Presets Block}\par
{\em User-\/configurable relay configuration presets with apply-\/on-\/startup feature.

Allows users to save up to 5 named relay configurations for quick recall. One preset can be designated to apply automatically on device startup. Includes header with magic value and CRC16 for data integrity.

Structure Layout (256 bytes total)\+:
\begin{DoxyItemize}
\item Header (4 bytes)\+:
\begin{DoxyItemize}
\item Magic byte (0x\+C5)\+: Data validity marker
\item Startup preset ID (0-\/4 or 0x\+FF for none)
\item Reserved (2 bytes)\+: Future expansion
\end{DoxyItemize}
\item Presets array (140 bytes = 5 × 28 bytes)\+:
\begin{DoxyItemize}
\item Each preset\+: Name (26 bytes) + Relay mask (1 byte) + Valid flag (1 byte)
\end{DoxyItemize}
\item CRC16 (2 bytes)\+: Checksum over header + presets (144 bytes)
\end{DoxyItemize}

Preset Structure (28 bytes each)\+:
\begin{DoxyItemize}
\item Name\+: 25-\/character null-\/terminated string
\item Null terminator\+: Byte 26
\item Relay mask\+: 8-\/bit mask (bit N = channel N state, 1=ON 0=OFF)
\item Valid flag\+: 0x\+A5 if preset used, else empty slot
\end{DoxyItemize}

\begin{DoxyItemize}
