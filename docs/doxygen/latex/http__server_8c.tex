\doxysubsection{Detailed Description}

Implementation of HTTP/1.\+1 server with route-\/based dispatching and chunked transfer. Provides web interface and REST API access with TX watchdog protection.

Key implementation\+: chunked sending breaks large responses into 4KB chunks with delays to avoid overflowing W5500\textquotesingle{}s 8KB TX buffer. Gzipped pages reduce transfer size.
