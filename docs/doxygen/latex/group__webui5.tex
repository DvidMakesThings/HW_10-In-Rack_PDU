\doxysubsubsection{Detailed Description}
HTML page content storage and retrieval for web interface. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/07
\end{DoxyDate}
This module provides a simple routing layer for HTML page content stored in flash memory. It maps HTTP request paths to appropriate HTML content arrays and returns their sizes.

Storage Strategy\+:
\begin{DoxyItemize}
\item Frequently accessed pages (control, settings, help) stored as gzip-\/compressed blobs
\item Infrequently accessed pages (manuals) stored as plain HTML strings
\item All content stored in flash memory to conserve RAM
\item Gzip compression reduces transfer size and mitigates W5500 TX buffer constraints
\end{DoxyItemize}

Supported Pages\+:
\begin{DoxyItemize}
\item Control page (control.\+html, root /) -\/ Main relay control interface (gzipped)
\item Settings page (settings.\+html) -\/ Network and device configuration (gzipped)
\item Help page (help.\+html) -\/ Quick reference and links (gzipped)
\item User Manual (user\+\_\+manual.\+html) -\/ PDF iframe embed (plain HTML)
\item Automation Manual (automation\+\_\+manual.\+html) -\/ PDF iframe embed (plain HTML)
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item HTTP server calls \doxylink{group__webui5_ga60e051c53a61100294f1cc857e73daf0}{get\+\_\+page\+\_\+content()} to retrieve pointer to HTML data
\item HTTP server calls \doxylink{group__webui5_ga50ef0aad6146999a05d9a34b3b5c4e32}{get\+\_\+page\+\_\+length()} to determine Content-\/\+Length and encoding
\item HTTP server sends appropriate Content-\/\+Encoding header based on gzip flag
\item Content is transmitted using chunked send to avoid buffer overflow
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
All page content is const and stored in flash; no runtime modifications. 

Gzipped pages use external const arrays from html/\texorpdfstring{$\ast$}{*}\+\_\+gz.h headers. 

Default fallback is control.\+html for unrecognized paths.
\end{DoxyNote}

Route HTTP request to appropriate HTML page content. 

Maps HTTP GET request paths to corresponding HTML content stored in flash memory. Supports both plain HTML strings and gzip-\/compressed blobs. Always returns a valid pointer (defaults to control page for unrecognized paths).

Routing Table\+:
\begin{DoxyItemize}
\item GET /settings.html → settings\+\_\+gz (gzipped)
\item GET /help.html → help\+\_\+gz (gzipped)
\item GET /user\+\_\+manual.html → user\+\_\+manual\+\_\+html (plain HTML)
\item GET /automation\+\_\+manual.html → automation\+\_\+manual\+\_\+html (plain HTML)
\item GET /control.html → control\+\_\+gz (gzipped)
\item GET / → control\+\_\+gz (gzipped, default)
\item All other paths → control\+\_\+gz (gzipped, fallback)
\end{DoxyItemize}

Get content length and encoding for a requested HTML page. 

Determines the byte length of the HTML content for a given HTTP request path and indicates whether the content is gzip-\/compressed. This information is used by the HTTP server to set Content-\/\+Length and Content-\/\+Encoding headers.

Length Calculation\+:
\begin{DoxyItemize}
\item Gzipped pages\+: Uses precompiled \texorpdfstring{$\ast$}{*}\+\_\+gz\+\_\+len constants from header files
\item Plain HTML pages\+: Uses strlen() to measure string length
\item Default fallback\+: Returns control\+\_\+gz length
\end{DoxyItemize}


\begin{DoxyParams}{Parameters}
{\em request} & HTTP request line (e.\+g., "{}\+GET /help.\+html HTTP/1.\+1"{}) \\
\hline
{\em is\+\_\+gzip} & Output flag indicating compression; set to 1 if gzipped, 0 if plain HTML (may be NULL)\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Content length in bytes (always positive)
\end{DoxyReturn}
\begin{DoxyNote}{Note}
If is\+\_\+gzip is NULL, the function still works but does not report encoding. 

Always returns a valid length; falls back to control\+\_\+gz on unrecognized paths.
\end{DoxyNote}
