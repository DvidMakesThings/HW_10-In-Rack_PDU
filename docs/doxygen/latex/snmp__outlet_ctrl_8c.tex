Implementation of SNMP outlet control callbacks using the synchronous Switch\+Task API v2.\+0. Provides deterministic GET/\+SET operations with hardware verification.

Design Principles\+:
\begin{DoxyItemize}
\item All operations are deterministic and synchronous
\item GET operations read directly from hardware (no cache)
\item SET operations block until hardware write is verified
\item Detailed error codes enable accurate SNMP response
\end{DoxyItemize}

SNMP SET Flow\+:
\begin{DoxyEnumerate}
\item SET request arrives from SNMP agent
\item \doxylink{snmp__outlet_ctrl_8c_a5259faefc9f865c528fc6cfe0ec51d1b}{setter\+\_\+n()} decodes and validates requested state
\item \doxylink{group__tasks11_gaef7818ff67a4d2235b897909f9fe6744}{Switch\+\_\+\+Set\+Channel\+Compat()} called (blocking)
\item Switch\+Task acquires mutex, executes I2C write
\item Hardware read-\/back verifies the write (up to 500ms polling)
\item Result returned and SNMP response sent with correct status
\end{DoxyEnumerate}

SNMP GET Flow\+:
\begin{DoxyEnumerate}
\item GET request arrives from SNMP agent
\item \doxylink{snmp__outlet_ctrl_8c_aae9111624ead3d3f32f8ec6f54c84363}{getter\+\_\+n()} calls \doxylink{group__tasks11_ga19c6dbf15503e4ca3c985e5acd42c278}{Switch\+\_\+\+Get\+State\+Compat()} (blocking)
\item Hardware read executed with mutex protection
\item Actual hardware state returned as 4-\/byte INTEGER
\item SNMP response sent with current value
\end{DoxyEnumerate}

Generic SNMP setter for outlet state. 

Sets the desired state of a specified outlet via synchronous Switch\+Task API. Implements strict "{}write-\/then-\/verify"{} semantics with active hardware polling.

Operation sequence\+:
\begin{DoxyEnumerate}
\item Decode and validate requested state (0=OFF, non-\/zero=ON)
\item Validate channel range (1..8)
\item Execute synchronous switch via \doxylink{group__tasks11_gaef7818ff67a4d2235b897909f9fe6744}{Switch\+\_\+\+Set\+Channel\+Compat()} (blocking)
\item Switch\+Task polls MCP23017 relay GPIO up to 500ms until state matches
\item Log error if channel invalid, switch fails, or timeout/mismatch occurs
\end{DoxyEnumerate}
