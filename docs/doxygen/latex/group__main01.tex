Global variable to trigger BOOTSEL mode. 

This variable is used to trigger the BOOTSEL mode on the next reboot.

Main entry point

Performs minimal initialization\+:
\begin{DoxyEnumerate}
\item Set system clock to 200 MHz for better network performance
\item Initialize stdio (USB-\/\+CDC) for early debug output
\item Create Init\+Task (high priority bring-\/up task)
\item Start Free\+RTOS scheduler
\end{DoxyEnumerate}
