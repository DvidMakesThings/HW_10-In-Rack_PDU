\doxysubsubsection{Detailed Description}
I2C driver for CAT24\+C256 32KB EEPROM with page-\/aware write operations. 

\begin{DoxyVersion}{Version}
1.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/06
\end{DoxyDate}
Provides thread-\/safe access to the CAT24\+C256 serial EEPROM used for non-\/volatile parameter storage in the ENERGIS PDU. The driver handles\+:
\begin{DoxyItemize}
\item 64-\/byte page boundary management for writes
\item Mandatory write cycle delays per datasheet timing
\item 16-\/bit address space (0x0000 -\/ 0x7\+FFF, 32KB total)
\item I2C bus arbitration via centralized bus manager
\end{DoxyItemize}

Key Features\+:
\begin{DoxyItemize}
\item Page-\/aware buffered writes prevent page boundary corruption
\item Automatic write cycle delays (5ms per page)
\item Sequential multi-\/byte reads without page restrictions
\item Self-\/test function for hardware validation
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item All operations must be called from Storage\+Task with eeprom\+Mtx protection
\item Uses i2c\+\_\+bus\+\_\+\texorpdfstring{$\ast$}{*} wrappers for serialized I2C access
\end{DoxyItemize}

Hardware Configuration\+:
\begin{DoxyItemize}
\item I2C address\+: 0x50 (7-\/bit)
\item Bus\+: I2\+C1 (configurable via \doxylink{_c_o_n_f_i_g_8h}{CONFIG.\+h})
\item Speed\+: Typically 100-\/400 k\+Hz
\end{DoxyItemize}

Execute comprehensive EEPROM self-\/test. 

Validates EEPROM functionality by writing and reading back a test pattern designed to detect common failure modes\+:

Test Pattern (8 bytes)\+:
\begin{DoxyItemize}
\item 0x\+AA, 0x55\+: Alternating bit patterns (detects stuck bits)
\item 0x\+CC, 0x33\+: Adjacent bit pairs (detects crosstalk)
\item 0x\+F0, 0x0F\+: Nibble patterns (detects partial byte errors)
\item 0x00, 0x\+FF\+: Extreme values (detects threshold issues)
\end{DoxyItemize}

Procedure\+:
\begin{DoxyEnumerate}
\item Write test pattern to specified address
\item Wait 10ms for write completion
\item Read back pattern
\item Compare byte-\/by-\/byte with expected values
\end{DoxyEnumerate}

Write buffer to EEPROM with automatic page boundary handling. 

Writes data in page-\/aligned chunks to prevent page boundary corruption. Automatically splits writes that cross 64-\/byte page boundaries into multiple operations with proper write cycle delays between each.

Page Boundary Example\+:
\begin{DoxyItemize}
\item Write 100 bytes starting at 0x0020\+:
\begin{DoxyItemize}
\item Chunk 1\+: 0x0020-\/0x003F (32 bytes to page boundary)
\item Delay 5ms
\item Chunk 2\+: 0x0040-\/0x007F (64 bytes, full page)
\item Delay 5ms
\item Chunk 3\+: 0x0080-\/0x0083 (4 bytes remaining)
\item Delay 5ms
\end{DoxyItemize}
