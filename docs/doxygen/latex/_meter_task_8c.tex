Meter\+Task implementation for power monitoring and system telemetry collection. This task is the exclusive owner of the HLW8032 power measurement peripheral and the RP2040 ADC subsystem. It polls all 8 power channels in round-\/robin fashion at 25 Hz and samples system ADC telemetry at 5 Hz.

Power Measurement Flow\+:
\begin{DoxyItemize}
\item Polls HLW8032 once per 40ms task period (25 Hz)
\item HLW8032 driver handles internal round-\/robin across 8 channels
\item Retrieves cached instantaneous values (voltage, current, power) per channel
\item Computes power factor from active power and apparent power
\item Integrates energy accumulation using power × time (k\+Wh)
\item Publishes telemetry to queue every 5th sample (\texorpdfstring{$\sim$}{\string~}200ms)
\end{DoxyItemize}

System Telemetry Flow\+:
\begin{DoxyItemize}
\item Samples ADC every 200ms for die temperature, VUSB, and 12V supply
\item Uses oversampling\+: 16× for voltage rails, 32× for temperature sensor
\item Applies calibrated temperature model with per-\/device parameters
\item Clamps temperature readings to plausible range (-\/20 to 120 °C)
\item Logs critical warnings if voltages or temperature out of safe range
\item Updates cached snapshot accessible via \doxylink{group__tasks06_ga909c8be3f0ce184e2cd1045bc29e0e30}{Meter\+Task\+\_\+\+Get\+System\+Telemetry()}
\end{DoxyItemize}

Standby Mode Behavior\+:
\begin{DoxyItemize}
\item Detects power state via \doxylink{group__misc3_gad3252fba1863d278f2611cad531177f5}{Power\+\_\+\+Get\+State()} each iteration
\item In STANDBY\+: skips all HLW8032 polling and ADC sampling
\item Maintains reduced heartbeat (500ms) to keep watchdog satisfied
\item Uses long delay (300ms) to minimize CPU usage during standby
\item Automatically resumes normal operation on transition back to RUN
\end{DoxyItemize}

Energy Accumulation\+:
\begin{DoxyItemize}
\item Tracks energy in k\+Wh with millisecond-\/resolution integration
\item Formula\+: delta\+\_\+k\+Wh = (power\+\_\+watts / 1000) × (delta\+\_\+ms / 3600000)
\item Accumulates only when relay is ON and power \texorpdfstring{$>$}{>} 0
\item Persists during runtime; resets to zero at boot
\end{DoxyItemize}

Temperature Calibration\+:
\begin{DoxyItemize}
\item Supports three modes\+: NONE (typicals), 1PT (offset), 2PT (slope+intercept)
\item Default model uses RP2040 typical values (V0=0.\+706V, S=0.\+001721V/°C)
\item Calibration parameters loaded from EEPROM at task init
\item Applied in \doxylink{_meter_task_8c_ac813b666061cf4dd0ff7bd15f385eb34}{adc\+\_\+raw\+\_\+to\+\_\+die\+\_\+temp\+\_\+c()} for all temperature conversions
\end{DoxyItemize}

Version History\+:
\begin{DoxyItemize}
\item v1.\+2.\+3\+: Removed rolling filter; now uses instantaneous HLW8032 values
\end{DoxyItemize}

Convert ADC raw code to RP2040 die temperature using per-\/device calibration. 

Applies the calibrated linear temperature model to convert a raw 12-\/bit ADC reading from the RP2040 internal die sensor (AINSEL=4) to temperature in °C.

Calibration Model\+: T\mbox{[}°C\mbox{]} = 27 -\/ (V -\/ V0) / S + OFFSET

Where\+:
\begin{DoxyItemize}
\item V = raw × (ADC\+\_\+\+VREF / ADC\+\_\+\+MAX) \mbox{[}voltage from ADC code\mbox{]}
\item V0 = s\+\_\+temp\+\_\+v0\+\_\+cal \mbox{[}intercept at 27 °C, default 0.\+706V\mbox{]}
\item S = s\+\_\+temp\+\_\+slope\+\_\+cal \mbox{[}slope, default 0.\+001721 V/°C\mbox{]}
\item OFFSET = s\+\_\+temp\+\_\+offset\+\_\+c \mbox{[}residual offset, default 0 °C\mbox{]}
\end{DoxyItemize}

Main Meter Task loop. 

In normal RUN mode, polls HLW8032 at 25 Hz, updates energy accumulation, samples ADC telemetry every 200ms, and publishes data to the queue.

In STANDBY mode, skips all hardware operations and only feeds heartbeat at a reduced rate with long delays to minimize CPU usage.
