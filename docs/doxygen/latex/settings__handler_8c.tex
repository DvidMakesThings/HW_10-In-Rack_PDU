Send data in safe chunks to avoid overflowing W5500 TX buffer. 

Splits large payloads into chunks of up to 4KB (SETTINGS\+\_\+\+MAX\+\_\+\+SEND\+\_\+\+CHUNK) and sends each chunk sequentially with a small delay between chunks to allow hardware TX drain. This prevents TX buffer overflow when sending large responses (e.\+g., gzipped HTML pages).

Transmit Strategy\+:
\begin{DoxyItemize}
\item Maximum chunk size\+: 4KB (fits comfortably in 8KB W5500 TX buffer)
\item Inter-\/chunk delay\+: 5ms (allows hardware to transmit buffered data)
\item Health heartbeat called after each chunk for watchdog
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item Returns -\/1 immediately if any \doxylink{group__drivers08_gacd77c3cc60e87d09a5714932506d7c4b}{send()} call fails
\item Logs structured error code to error logger on failure
\item No retry or recovery; caller must handle errors
\end{DoxyItemize}
