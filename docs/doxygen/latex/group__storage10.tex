\doxysubsubsection{Detailed Description}
Serial Number and Region Management with EEPROM Persistence. 

\begin{DoxyVersion}{Version}
1.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/14
\end{DoxyDate}
This module provides centralized management of device identity parameters\+:
\begin{DoxyItemize}
\item Serial number (up to 15 characters + null terminator)
\item Region setting (EU / US)
\end{DoxyItemize}

Architecture\+:
\begin{DoxyItemize}
\item RAM cache provides fast, lock-\/free read access for all modules
\item EEPROM provides non-\/volatile persistence with CRC-\/8 validation
\item EEPROM layout is defined {\bfseries{exclusively}} in \doxylink{_e_e_p_r_o_m___memory_map_8h}{EEPROM\+\_\+\+Memory\+Map.\+h}
\item No module is allowed to redefine EEPROM address or size locally
\end{DoxyItemize}

Provisioning\+:
\begin{DoxyItemize}
\item Requires explicit unlock with a fixed token
\item Unlock opens a time-\/limited write window
\item Writes are rejected outside the window
\end{DoxyItemize}

IMPORTANT\+:
\begin{DoxyItemize}
\item All consumers must read identity {\bfseries{only from the RAM cache}}
\item EEPROM is accessed only by this module
\end{DoxyItemize}

Initialize the device identity module. 

Loads device identity from EEPROM into the RAM cache. If EEPROM data is invalid (CRC mismatch or empty), the cache is marked invalid and default placeholder values are used.

This function must be called early in the boot sequence, after EEPROM driver initialization but before any module that needs SN/region access.

\begin{DoxyNote}{Note}
Thread-\/safe. May be called before scheduler starts. 
\end{DoxyNote}
