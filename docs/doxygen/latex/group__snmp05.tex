\doxysubsubsection{Detailed Description}
RP2040 internal rails, die temperature, and project voltage monitoring. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/07
\end{DoxyDate}
This module provides SNMP GET callbacks that expose RP2040 internal voltage rails, on-\/die temperature sensor, and project-\/specific power supply voltages. All measurements are retrieved from Meter\+Task\textquotesingle{}s system telemetry cache.

Monitored Parameters\+:

RP2040 Internal Measurements\+:
\begin{DoxyItemize}
\item Die Temperature Sensor Voltage -\/ Raw ADC voltage from internal temperature sensor
\item Die Temperature -\/ Converted temperature in Celsius
\item Core VREG Voltage -\/ Adjustable core voltage regulator setting (0.\+85V + 0.\+05V \texorpdfstring{$\ast$}{*} VSEL)
\item Core VREG Status -\/ Regulator status (OK/\+Overload/\+Hi-\/Z)
\item Bandgap Reference -\/ Fixed 1.\+10V reference
\item USB PHY Rail -\/ Fixed 1.\+80V USB PHY supply
\item IO Rail -\/ Fixed 3.\+30V IO supply
\end{DoxyItemize}

Project-\/\+Specific Measurements\+:
\begin{DoxyItemize}
\item V\+\_\+\+SUPPLY -\/ Main power supply voltage (measured via voltage divider)
\item V\+\_\+\+USB -\/ USB power supply voltage (measured via voltage divider)
\item V\+\_\+\+SUPPLY Divider Tap -\/ Pre-\/divider voltage at ADC input
\item V\+\_\+\+USB Divider Tap -\/ Pre-\/divider voltage at ADC input
\end{DoxyItemize}

All voltage measurements are returned as ASCII float strings with appropriate precision (typically 2-\/3 decimals). Temperature is reported in degrees Celsius. Fixed voltages return constant string values for efficiency.

Telemetry Source\+:
\begin{DoxyItemize}
\item Internal sensors\+: RP2040 ADC channel 4 (temperature sensor)
\item External voltages\+: RP2040 ADC channels with resistive dividers
\item All readings cached by Meter\+Task at approximately 1 Hz
\end{DoxyItemize}

\begin{DoxyNote}{Note}
All functions are RTOS-\/safe and non-\/blocking. 

Returns zeros if telemetry unavailable or invalid.
\end{DoxyNote}
