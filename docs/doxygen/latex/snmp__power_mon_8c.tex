Implementation of SNMP power monitoring callbacks. All telemetry data is read from Meter\+Task\textquotesingle{}s canonical cache using non-\/blocking operations. If telemetry is invalid or unavailable, functions return zero values to ensure SNMP queries always receive valid responses.

The module uses macro-\/generated functions (GEN\+\_\+\+CH) to create 6 telemetry getters per channel (voltage, current, power, power factor, energy, uptime) for all 8 outlets. OCP status functions access the overcurrent protection module directly via \doxylink{group__tasks08_gaa9aab2a7bfb3274872c5f4f162af177e}{Overcurrent\+\_\+\+Get\+Status()}.

Macro to generate six SNMP telemetry getters for a channel. 

Generates the following functions for channel N (idx)\+:
\begin{DoxyItemize}
\item get\+\_\+power\+\_\+\+N\+\_\+\+MEAS\+\_\+\+VOLTAGE\+: Voltage \mbox{[}V\mbox{]} as ASCII float (2 decimals)
\item get\+\_\+power\+\_\+\+N\+\_\+\+MEAS\+\_\+\+CURRENT\+: Current \mbox{[}A\mbox{]} as ASCII float (3 decimals)
\item get\+\_\+power\+\_\+\+N\+\_\+\+MEAS\+\_\+\+WATT\+: Power \mbox{[}W\mbox{]} as ASCII float (1 decimal)
\item get\+\_\+power\+\_\+\+N\+\_\+\+MEAS\+\_\+\+PF\+: Power factor as ASCII float (3 decimals)
\item get\+\_\+power\+\_\+\+N\+\_\+\+MEAS\+\_\+\+KWH\+: Energy \mbox{[}k\+Wh\mbox{]} as ASCII float (3 decimals)
\item get\+\_\+power\+\_\+\+N\+\_\+\+MEAS\+\_\+\+UPTIME\+: Uptime \mbox{[}s\mbox{]} as ASCII unsigned integer
\end{DoxyItemize}

Each generated function reads telemetry from Meter\+Task cache via \doxylink{snmp__power_mon_8c_a2f3700d5c752414ae1faad14def54875}{read\+N()} and formats the appropriate field using \doxylink{snmp__power_mon_8c_af45f37256bc0bbee50f12561e810efda}{ftoa()} or \doxylink{snmp__power_mon_8c_a906d1e27977299ca0024205545d05dc7}{u32toa()}.
