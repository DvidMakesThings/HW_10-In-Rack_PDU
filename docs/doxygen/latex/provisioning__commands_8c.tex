Trim leading and trailing whitespace/control chars in-\/place. 

UART/\+USB-\/\+CDC command lines typically end with "{}\textbackslash{}r\textbackslash{}n"{}. The Device\+Identity validation is intentionally strict and rejects whitespace/control chars. Therefore, provisioning subcommand arguments must be trimmed before use.
