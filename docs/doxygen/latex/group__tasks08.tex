\doxysubsubsection{Detailed Description}
High-\/priority overcurrent monitoring and protection system. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/11
\end{DoxyDate}
This module provides real-\/time overcurrent protection for the ENERGIS PDU. It monitors the total current draw across all 8 channels and implements a tiered response system\+:

{\bfseries{Threshold Levels (relative to ENERGIS\+\_\+\+CURRENT\+\_\+\+LIMIT\+\_\+A)\+:}}
\begin{DoxyItemize}
\item WARNING (Limit -\/ 1.\+0A)\+: Raises ERR\+\_\+\+SEV\+\_\+\+ERROR, logs warning
\item CRITICAL (Limit -\/ 0.\+25A)\+: Raises ERR\+\_\+\+FATAL\+\_\+\+ERROR, trips last channel, locks switching
\item RECOVERY (Limit -\/ 2.\+0A)\+: Clears lockout when current falls below this level
\end{DoxyItemize}

{\bfseries{Regional Limits\+:}}
\begin{DoxyItemize}
\item EU Version\+: 10.\+0A (IEC/\+ENEC)
\item US Version\+: 15.\+0A (UL/\+CSA)
\end{DoxyItemize}

{\bfseries{Architecture\+:}}
\begin{DoxyItemize}
\item Meter\+Task calls \doxylink{group__tasks08_gabb9789239f4931927587b1b236b1e315}{Overcurrent\+\_\+\+Update()} after each complete 8-\/channel measurement cycle
\item Switch\+Task queries \doxylink{group__tasks08_ga4bf47606df6e10c610300fdf1a2573b5}{Overcurrent\+\_\+\+Is\+Switching\+Allowed()} before executing relay commands
\item All control handlers (HTTP, SNMP, Console) receive rejection when locked out
\end{DoxyItemize}

Sets up thresholds based on regional configuration (EU/\+US) and initializes the protection state machine. Must be called during system initialization before Meter\+Task begins monitoring.

Thread-\/safe. Can be called from any task context.
\end{DoxyNote}
Computes state machine thresholds from runtime configuration obtained from the Device\+Identity module. The region setting in EEPROM determines the appropriate current limit (10A EU / 15A US).

Threshold derivation\+:
\begin{DoxyItemize}
\item s\+\_\+limit\+\_\+a is sourced from \doxylink{group__storage03_ga5b4f82b48868c1a68c60a9fc9a7f3e37}{Device\+Identity\+\_\+\+Get\+Current\+Limit\+A()}

\item s\+\_\+critical\+\_\+threshold\+\_\+a = s\+\_\+limit\+\_\+a -\/ ENERGIS\+\_\+\+CURRENT\+\_\+\+SAFETY\+\_\+\+MARGIN\+\_\+A
\item s\+\_\+recovery\+\_\+threshold\+\_\+a = s\+\_\+limit\+\_\+a -\/ ENERGIS\+\_\+\+CURRENT\+\_\+\+RECOVERY\+\_\+\+OFFSET\+\_\+A
\end{DoxyItemize}

State initialization\+:
\begin{DoxyItemize}
\item Sets state to NORMAL
\item Clears current measurement cache and trip bookkeeping
\item Enables switching
\item Marks the module initialized after all values are set
\end{DoxyItemize}

\begin{DoxyNote}{Note}
\doxylink{group__storage03_ga8a44399536e0b86e0b543df9f1962c17}{Device\+Identity\+\_\+\+Init()} must be called before this function to ensure the region setting is available. If Device\+Identity returns UNKNOWN region, the safe default (10A) is used.

Update overcurrent protection with new total current measurement.

This function is the evaluation core of the overcurrent protection module. It is intended to be called periodically (typically once per full measurement cycle) with the aggregated total current in amperes.

Processing steps\+:
\begin{DoxyEnumerate}
\item Reject processing if the module is not initialized.
\item Apply a sanity filter to reject invalid measurements.
\item Store the latest accepted measurement for status reporting.
\item Evaluate the state machine based on thresholds and hysteresis.
\item Execute transition side effects\+:
\begin{DoxyItemize}
\item WARNING\+: log once to avoid repeated messages
\item LOCKOUT\+: trip action, lock switching, update trip bookkeeping, log error
\item RECOVERY\+: unlock switching and clear warning latch
\end{DoxyItemize}
\end{DoxyEnumerate}

State behavior\+:
\begin{DoxyItemize}
\item NORMAL\+:
\begin{DoxyItemize}
\item Enters WARNING when total\+\_\+current\+\_\+a \texorpdfstring{$>$}{>}= warning threshold
\item Enters CRITICAL when total\+\_\+current\+\_\+a \texorpdfstring{$>$}{>}= critical threshold
\end{DoxyItemize}
\item WARNING\+:
\begin{DoxyItemize}
\item Enters CRITICAL when total\+\_\+current\+\_\+a \texorpdfstring{$>$}{>}= critical threshold
\item Returns to NORMAL when total\+\_\+current\+\_\+a \texorpdfstring{$<$}{<} warning threshold
\end{DoxyItemize}
\item CRITICAL\+:
\begin{DoxyItemize}
\item Enters LOCKOUT only if total\+\_\+current\+\_\+a is still \texorpdfstring{$>$}{>}= critical threshold
\item Returns to NORMAL if the measurement is below the critical threshold
\end{DoxyItemize}
\item LOCKOUT\+:
\begin{DoxyItemize}
\item Returns to NORMAL (recovery) when total\+\_\+current\+\_\+a \texorpdfstring{$<$}{<} recovery threshold
\end{DoxyItemize}
\end{DoxyItemize}
