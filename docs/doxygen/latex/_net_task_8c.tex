Net\+Task owns all W5500 operations. It waits for Storage\+Task to signal that configuration is ready, reads the network config, brings up the W5500, then runs the web server loop.

The task is explicitly robust against missing or interrupted Ethernet link\+:
\begin{DoxyItemize}
\item If the PDU boots without a cable, the rest of the system still runs.
\item ETH LED blinks while there is no PHY link.
\item On each link-\/up transition, the W5500 is fully reinitialized and all IP-\/based services (HTTP + SNMP) are restarted to avoid ERR\+\_\+\+CONNECTION\+\_\+\+REFUSED.
\end{DoxyItemize}

Standby mode support\+:
\begin{DoxyItemize}
\item When system enters STANDBY mode (via \doxylink{group__misc3_ga40de5935f9ba85f9141a9243b4d02c87}{Power\+\_\+\+Enter\+Standby()}), Net\+Task stops all W5500 access, HTTP, and SNMP processing.
\item The W5500 is held in hardware reset by \doxylink{group__misc3_ga40de5935f9ba85f9141a9243b4d02c87}{Power\+\_\+\+Enter\+Standby()}.
\item Net\+Task continues running but only feeds heartbeat and delays.
\item On exit from STANDBY (via \doxylink{group__misc3_gafa726e9d0fc140faa3f54c6905ac2520}{Power\+\_\+\+Exit\+Standby()}), Net\+Task detects the state transition and calls \doxylink{_net_task_8c_a69d051e31c6438ed93d21deb141e4795}{net\+\_\+reinit\+\_\+from\+\_\+cache()} to restore network.
\end{DoxyItemize}
