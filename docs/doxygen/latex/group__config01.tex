It describes GPIO pin assignments, I2\+C/\+SPI peripheral usage, ADC channel assignments, and other peripheral configurations.

Switch/display policy flags
\begin{DoxyItemize}
\item When 0, relay switching proceeds even if display mirror writes fail.
\item When 1, display mirror failures make the overall switch operation fail. When enabled (1), any failure to mirror the relay state to the display MCP (0x21) will cause \doxylink{group__tasks11_gabd8f13f37bd62b267259ae2d027bda28}{Switch\+\_\+\+Set\+Channel()} to fail. When disabled (0), display mirror is treated as best-\/effort\+: failure is logged as a warning but switching proceeds.
