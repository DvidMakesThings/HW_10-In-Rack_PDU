\doxysubsubsubsection{Detailed Description}
Fixed threshold offsets for overcurrent state machine. 

These thresholds are fixed offsets applied to the regional current limit. The actual limit (10A EU / 15A US) is determined at runtime from EEPROM.

State Machine\+:
\begin{DoxyItemize}
\item NORMAL\+: Current \texorpdfstring{$<$}{<} (LIMIT -\/ WARNING\+\_\+\+OFFSET)
\item WARNING\+: Current \texorpdfstring{$>$}{>}= (LIMIT -\/ WARNING\+\_\+\+OFFSET)
\item CRITICAL\+: Current \texorpdfstring{$>$}{>}= (LIMIT -\/ SAFETY\+\_\+\+MARGIN)
\item LOCKOUT\+: Trip executed, switching disabled
\item RECOVERY\+: Current \texorpdfstring{$<$}{<} (LIMIT -\/ RECOVERY\+\_\+\+OFFSET) 
\end{DoxyItemize}
