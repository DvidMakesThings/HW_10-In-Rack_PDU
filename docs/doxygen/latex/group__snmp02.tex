\doxysubsubsection{Detailed Description}
Network configuration exposure via SNMP. 

\begin{DoxyVersion}{Version}
1.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/08
\end{DoxyDate}
This module provides SNMP GET callbacks that expose the device\textquotesingle{}s network configuration as read-\/only OCTET\+\_\+\+STRING values. Network parameters are retrieved from persistent storage (EEPROM) via the Storage\+Task API.

Exposed network parameters\+:
\begin{DoxyItemize}
\item IP address (dotted-\/decimal notation)
\item Subnet mask (dotted-\/decimal notation)
\item Gateway address (dotted-\/decimal notation)
\item DNS server address (dotted-\/decimal notation)
\item MAC address (colon-\/separated hexadecimal)
\end{DoxyItemize}

If storage access fails, functions automatically fall back to compiled-\/in default values to ensure SNMP queries always return valid data.

All functions are RTOS-\/safe and can be called from the SNMP agent context without blocking other tasks.

\begin{DoxyNote}{Note}
These are read-\/only OIDs; network configuration must be modified via the web interface or console commands. 
\end{DoxyNote}
