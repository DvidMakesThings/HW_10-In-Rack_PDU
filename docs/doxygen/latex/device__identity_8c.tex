Implementation of device identity management module. Provides centralized storage and access for serial number and region settings with EEPROM persistence and RAM caching.

Thread Safety\+:
\begin{DoxyItemize}
\item Read operations are lock-\/free (atomic cache access)
\item Write operations acquire eeprom\+Mtx for EEPROM access
\item Unlock state uses atomic timestamp comparison
\end{DoxyItemize}

EEPROM Block Contract\+:
\begin{DoxyItemize}
\item EEPROM\+\_\+\+DEVICE\+\_\+\+IDENTITY\+\_\+\+START / EEPROM\+\_\+\+DEVICE\+\_\+\+IDENTITY\+\_\+\+SIZE define the stored block
\item Region is stored at offset 0x10, CRC at 0x11, pad at 0x12
\item CRC is calculated over bytes 0x00..0x10 (serial + region)
\item Pad byte is written deterministically as 0x00 for a stable block image
\end{DoxyItemize}
