Execute overcurrent trip action. 

Attempts to disable the last channel that was successfully enabled and recorded via \doxylink{group__tasks08_ga05298731bbc499e043d911ec1ca59879}{Overcurrent\+\_\+\+Record\+Channel\+On()}. If no valid channel is tracked, all channels are disabled as a safety fallback.

Behavior\+:
\begin{DoxyItemize}
\item If s\+\_\+last\+\_\+activated\+\_\+channel is in range \mbox{[}0..7\mbox{]}, that channel is turned OFF.
\item Otherwise, all channels are turned OFF.
\end{DoxyItemize}

Notes\+:
\begin{DoxyItemize}
\item The actual relay switching is delegated to Switch\+Task via non-\/blocking API calls.
\item Logging is performed to indicate the applied protective action.
\end{DoxyItemize}

\begin{DoxyReturn}{Returns}
uint8\+\_\+t Returns the logical channel index \mbox{[}0..7\mbox{]} that was turned OFF, or 0x\+FF if the fallback "{}all OFF"{} action was used. 
\end{DoxyReturn}

Sanitize a current limit value obtained from configuration. 

This module must never operate with an invalid or near-\/zero limit value, because the WARNING state triggers when total\+\_\+current\+\_\+a \texorpdfstring{$>$}{>}= (limit -\/ offset). If limit is 0 or very small, the derived thresholds become negative and will produce false WARNING logs even at 0.\+00A (all outputs OFF).

The identity/config layer is expected to provide 10A (EU) or 15A (US). If it does not, we fall back to a safe regional default.
