\doxysubsection{Detailed Description}
Retained early-\/boot snapshot persisted in noinit RAM. 

The structure is intentionally simple and self-\/contained so it can be written before any subsystem is up. It captures information that is useful to diagnose watchdog bites and reset causes without relying on the logger at that time.
