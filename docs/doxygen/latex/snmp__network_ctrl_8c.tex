Implementation of SNMP network configuration getters. This module reads the persisted network configuration from EEPROM via Storage\+Task and formats network addresses as human-\/readable strings for SNMP responses.

Formatting conventions\+:
\begin{DoxyItemize}
\item IPv4 addresses\+: dotted-\/decimal (e.\+g., "{}192.\+168.\+1.\+100"{})
\item MAC addresses\+: colon-\/separated hex (e.\+g., "{}02\+:45\+:4\+E\+:0\+C\+:7\+B\+:1\+C"{})
\end{DoxyItemize}

All functions include error handling with automatic fallback to compiled defaults if storage access fails.
