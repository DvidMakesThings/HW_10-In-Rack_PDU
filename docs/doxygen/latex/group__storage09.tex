\doxysubsubsubsection{Detailed Description}
User output configuration presets and apply-\/on-\/startup persistence. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/01-\/01
\end{DoxyDate}
Manages up to 5 saveable relay configuration presets in EEPROM. Each preset contains a user-\/defined name (max 25 chars) and an 8-\/bit relay state mask. One preset can be designated as "{}apply-\/on-\/startup"{} to automatically configure relay states after device boot.

Memory Layout (0x0200-\/0x02\+FF, 256 bytes)\+:
\begin{DoxyItemize}
\item Byte 0\+: Header magic (0x\+C5)
\item Byte 1\+: Startup preset ID (0-\/4) or 0x\+FF for none
\item Bytes 2-\/3\+: Reserved
\item Bytes 4-\/143\+: 5 presets × 28 bytes each
\begin{DoxyItemize}
\item Bytes 0-\/24\+: Name (25 chars)
\item Byte 25\+: Null terminator
\item Byte 26\+: Relay mask (bit N = channel N state)
\item Byte 27\+: Valid flag (0x\+A5 = valid, else empty)
\end{DoxyItemize}
\item Bytes 144-\/145\+: CRC16 over bytes 0-\/143
\end{DoxyItemize}

RAM Caching\+:
\begin{DoxyItemize}
\item Presets are loaded into RAM on startup
\item API functions operate on RAM cache
\item EEPROM is written only on changes
\item Thread-\/safe via eeprom\+Mtx
\end{DoxyItemize}
