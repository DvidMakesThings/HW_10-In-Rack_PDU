\doxysubsubsection{Detailed Description}
Synchronous relay and LED control manager with MCP23017 GPIO expanders. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/17
\end{DoxyDate}
This module implements a Free\+RTOS task for managing relay switching and LED display control via three MCP23017 GPIO expanders. It provides deterministic, synchronous operations with mutex protection and comprehensive error handling.

Architecture\+:
\begin{DoxyItemize}
\item Single global mutex serializes all MCP23017 I2C access
\item Synchronous/blocking API\+: all operations complete before returning
\item Direct driver calls\+: no internal queues or deferred operations
\item Hardware state caching\+: reduces I2C traffic for frequent reads
\item Relay-\/to-\/\+LED mirroring\+: visual feedback for relay state on front panel
\item Background maintenance\+: periodic hardware sync and health monitoring
\end{DoxyItemize}

Key Features\+:
\begin{DoxyItemize}
\item 8-\/channel relay control with individual ON/\+OFF operations
\item All-\/\+ON and All-\/\+OFF bulk operations for emergency control
\item Selection window management for manual button interface
\item LED control (relay indicators, power LED, Ethernet LED, selection LEDs)
\item Hardware state verification\+: read-\/back confirms successful relay actuation
\item Overcurrent protection integration\+: rejects operations during lockout
\item Result codes\+: detailed error reporting for deterministic handling
\item Periodic hardware synchronization\+: detects external state changes
\end{DoxyItemize}

Hardware Configuration\+:
\begin{DoxyItemize}
\item MCP\+\_\+\+RELAY (0x20)\+: 8 relay channels on GPIOA, unused GPIOB
\item MCP\+\_\+\+LED1 (0x21)\+: Relay 1-\/4 LEDs, selection LEDs, power/\+ETH LEDs
\item MCP\+\_\+\+DISPLAY (0x22)\+: Relay 5-\/8 LEDs, 7-\/segment displays (not managed here)
\end{DoxyItemize}

API Design Philosophy\+:
\begin{DoxyItemize}
\item Synchronous operations for predictable timing and error handling
\item Immediate feedback\+: success/failure known before function returns
\item No hidden state\+: every operation directly reflects hardware intent
\item Mutex-\/protected\+: thread-\/safe from multiple task contexts
\item Detailed result codes\+: enables proper error handling in callers
\end{DoxyItemize}

Relay Control Flow\+:
\begin{DoxyEnumerate}
\item Caller invokes Switch\+\_\+\+Set\+Channel(channel, state)
\item Mutex acquired with timeout (rejects if busy)
\item Overcurrent check\+: rejects if OCP in lockout
\item Relay write via MCP\+\_\+\+RELAY driver
\item LED mirror write via MCP\+\_\+\+LED1/\+MCP\+\_\+\+DISPLAY (best-\/effort)
\item Hardware read-\/back verification
\item Cache update if verification successful
\item Mutex released, result code returned
\end{DoxyEnumerate}

Selection Window\+:
\begin{DoxyItemize}
\item Button\+Task manages selection (PLUS/\+MINUS buttons)
\item Switch\+Task provides Switch\+\_\+\+Set\+Selection() to update display LEDs
\item Wraps around at channel boundaries (0→7→0)
\item Visual feedback via illuminated LED on front panel
\end{DoxyItemize}

LED Mirroring\+:
\begin{DoxyItemize}
\item Relay ON → corresponding LED ON (channels 1-\/8)
\item Best-\/effort\+: LED failure doesn\textquotesingle{}t abort relay operation
\item Retry with backoff on I2C errors
\item Cache prevents redundant LED writes
\end{DoxyItemize}

Overcurrent Protection Integration\+:
\begin{DoxyItemize}
\item Queries \doxylink{group__tasks08_ga4bf47606df6e10c610300fdf1a2573b5}{Overcurrent\+\_\+\+Is\+Switching\+Allowed()} before relay ON operations
\item Returns SWITCH\+\_\+\+ERR\+\_\+\+OVERCURRENT if OCP in lockout
\item Prevents relay closure when total current exceeds safety threshold
\item Does not block relay OFF operations (always safe)
\end{DoxyItemize}

Hardware State Cache\+:
\begin{DoxyItemize}
\item 8-\/bit bitmask tracks last known relay states
\item Updated on successful write+verify
\item Periodically refreshed from hardware (5-\/second interval)
\item \doxylink{group__tasks11_ga84e3359029bd29e598f346dad2255899}{Switch\+\_\+\+Get\+State()} reads hardware directly (not cached)
\item \doxylink{group__tasks11_ga622d027de675f1438882d66f24d6bdb7}{Switch\+\_\+\+Get\+All\+States()} reads hardware directly (not cached)
\end{DoxyItemize}

Background Maintenance Task\+:
\begin{DoxyItemize}
\item Runs at 100ms period (SWITCH\+\_\+\+TASK\+\_\+\+PERIOD\+\_\+\+MS)
\item Sends periodic heartbeat to Health\+Task
\item Syncs cache from hardware every 5 seconds
\item Minimal CPU usage when idle
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item Global mutex protects all MCP23017 access
\item Timeout prevents indefinite blocking (1-\/second default)
\item Safe to call from any task context
\item Not safe from ISR context (use task notifications instead)
\end{DoxyItemize}

Error Handling\+:
\begin{DoxyItemize}
\item All operations return \doxylink{group__tasks11_ga64f3e0ad0f68b11e5283c8f9c6f551ea}{switch\+\_\+result\+\_\+t} with detailed status
\item I2C failures logged with diagnostic codes
\item Verification failures trigger retry with exponential backoff
\item Mutex timeout returns error without blocking forever
\item Overcurrent rejection logged for diagnostics
\end{DoxyItemize}

Integration Points\+:
\begin{DoxyItemize}
\item Button\+Task\+: manages selection window via Switch\+\_\+\+Set\+Selection()
\item Init\+Task\+: applies startup relay configuration from Storage\+Task
\item HTTP/\+SNMP handlers\+: control relays via \doxylink{group__tasks11_gabd8f13f37bd62b267259ae2d027bda28}{Switch\+\_\+\+Set\+Channel()}
\item Console\+Task\+: provides diagnostic commands and bulk operations
\item Overcurrent protection\+: gates relay ON operations during lockout
\item Health\+Task\+: receives periodic heartbeat for watchdog monitoring
\end{DoxyItemize}

\begin{DoxyNote}{Note}
All APIs are synchronous/blocking; do not call from ISR context. 

Mutex timeout is 1 second; operations fail if MCP I2C is hung. 

LED mirror failures are logged but don\textquotesingle{}t abort relay operations. 

Cache is best-\/effort; use \doxylink{group__tasks11_ga84e3359029bd29e598f346dad2255899}{Switch\+\_\+\+Get\+State()} for authoritative reads.
\end{DoxyNote}
