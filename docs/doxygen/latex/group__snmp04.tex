\doxysubsubsection{Detailed Description}
Per-\/channel power telemetry and overcurrent protection status via SNMP. 

\begin{DoxyVersion}{Version}
1.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/08
\end{DoxyDate}
This module provides SNMP GET callbacks that expose per-\/outlet power telemetry and system-\/wide overcurrent protection status. All telemetry data is retrieved from Meter\+Task\textquotesingle{}s canonical cache for efficient non-\/blocking access.

Per-\/\+Channel Telemetry (8 outlets)\+:
\begin{DoxyItemize}
\item Voltage \mbox{[}V\mbox{]} -\/ RMS voltage measurement (ASCII float, 2 decimals)
\item Current \mbox{[}A\mbox{]} -\/ RMS current measurement (ASCII float, 3 decimals)
\item Power \mbox{[}W\mbox{]} -\/ Active power measurement (ASCII float, 1 decimal)
\item Power Factor -\/ Dimensionless ratio 0..1 (ASCII float, 3 decimals)
\item Energy \mbox{[}k\+Wh\mbox{]} -\/ Accumulated energy since outlet powered on (ASCII float, 3 decimals)
\item Uptime \mbox{[}s\mbox{]} -\/ Time since outlet last powered on (ASCII integer)
\end{DoxyItemize}

Overcurrent Protection (OCP) Status\+:
\begin{DoxyItemize}
\item State -\/ NORMAL/\+WARNING/\+CRITICAL/\+LOCKOUT (INTEGER 0..3)
\item Total Current -\/ Sum of all outlet currents (ASCII float, 3 decimals)
\item Configured Limit -\/ OCP trip threshold (ASCII float, 2 decimals)
\item Warning/\+Critical/\+Recovery Thresholds (ASCII float, 2 decimals)
\item Last Tripped Channel -\/ 1-\/based outlet index or 0 (INTEGER)
\item Trip Counter -\/ Number of trips since boot (INTEGER)
\item Last Trip Timestamp -\/ Milliseconds since boot (INTEGER)
\item Switching Allowed -\/ 0=LOCKOUT, 1=allowed (INTEGER)
\item Reset Control -\/ Write non-\/zero to clear lockout (SET-\/only)
\end{DoxyItemize}

All telemetry reads are non-\/blocking and RTOS-\/safe. If telemetry is invalid or unavailable, functions return zero values rather than blocking or failing.

\begin{DoxyNote}{Note}
All functions can be safely called from SNMP agent context. 

Telemetry cache is updated by Meter\+Task at approximately 1 Hz.
\end{DoxyNote}
