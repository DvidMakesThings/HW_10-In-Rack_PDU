\doxysubsubsection{Detailed Description}
Handler for GET /api/status endpoint providing system telemetry. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/01-\/01
\end{DoxyDate}
This module handles GET requests to /api/status and returns a comprehensive JSON response containing all system telemetry and status information. The handler aggregates data from multiple subsystems using cached values to provide immediate responses without blocking on hardware measurements.

Data Sources\+:
\begin{DoxyItemize}
\item Channel states\+: Cached from Switch\+Task (updated in real-\/time by relay control)
\item Power metrics\+: Cached from Meter\+Task (updated periodically by HLW8032 measurements)
\item Channel labels\+: Retrieved from RAM cache (synchronized with EEPROM by Storage\+Task)
\item Internal temperature\+: Cached die temperature from Meter\+Task (updated with power metrics)
\item Overcurrent status\+: Real-\/time status from Overcurrent Protection module
\end{DoxyItemize}

Architecture Benefits\+:
\begin{DoxyItemize}
\item Non-\/blocking\+: All data retrieved from caches; no waiting for I2C, SPI, or UART
\item Fast response\+: Typical response time \texorpdfstring{$<$}{<}10ms regardless of measurement cadence
\item Consistency\+: All readings timestamped from same source (task-\/maintained caches)
\item Decoupling\+: UI refresh rate independent of hardware measurement intervals
\end{DoxyItemize}

Handle GET /api/status endpoint and return JSON telemetry. 

Aggregates system status from multiple cached sources and formats a comprehensive JSON response containing all channel states, power measurements, labels, temperature, and overcurrent protection status. All data is retrieved from RAM caches maintained by other tasks, ensuring fast non-\/blocking response regardless of hardware timing.

Operation\+:
\begin{DoxyEnumerate}
\item Retrieve cached die temperature from Meter\+Task
\item Load user preference for temperature unit (Celsius/\+Fahrenheit/\+Kelvin)
\item Snapshot all 8 channel relay states from Switch\+Task cache
\item Retrieve overcurrent protection status and determine system status
\item Load all channel labels from RAM cache (EEPROM-\/synchronized)
\item Build JSON array with per-\/channel telemetry (voltage, current, power, uptime, state, label)
\item Append temperature, system status, and overcurrent details to JSON
\item Send HTTP 200 OK response with JSON body and CORS headers
\end{DoxyEnumerate}

JSON Safety\+:
\begin{DoxyItemize}
\item Channel labels are JSON-\/escaped to handle quotes, backslashes, and control chars
\item All numeric values formatted with fixed precision
\item Boolean values rendered as true/false literals
\end{DoxyItemize}
