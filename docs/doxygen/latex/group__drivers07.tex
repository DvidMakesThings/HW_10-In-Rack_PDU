\doxysubsubsection{Detailed Description}
Header file for non-\/blocking SNMPv1 agent with UDP transport. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/07 đ
\end{DoxyDate}
SNMP agent for ENERGIS RTOS. Owns a UDP socket (port 161), parses incoming PDUs and emits responses without blocking the scheduler. Time base is 10 ms via \doxylink{group__drivers07_gaf6784b34d0637f242ccbde5945d27ca9}{SNMP\+\_\+\+Tick10ms()}, used for Time\+Ticks.

Service pending SNMP datagrams without blocking.

Non-\/blocking service routine that processes up to {\ttfamily max\+\_\+packets} SNMPv1 requests from the UDP socket bound to port 161, and emits corresponding Get\+Response PDUs. This variant relies on the W5500-\/style datagram reader \doxylink{group__drivers08_gaa2d7390eb4454dd102f39caf47829065}{recvfrom\+\_\+\+SNMP()}, which already consumes the 8-\/byte UDP datagram header (src IP\mbox{[}4\mbox{]}, src port\mbox{[}2\mbox{]}, payload length\mbox{[}2\mbox{]}) and returns the pure ASN.\+1 payload starting with 0x30.

Robustness\+:
