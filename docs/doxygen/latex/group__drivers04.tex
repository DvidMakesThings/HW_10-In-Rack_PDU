\doxysubsubsection{Detailed Description}
RTOS-\/safe driver for HLW8032 power measurement IC. 

\begin{DoxyVersion}{Version}
1.\+1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/11
\end{DoxyDate}
RTOS-\/safe driver for interfacing with HLW8032 power measurement chips. Features\+:
\begin{DoxyItemize}
\item Mutex-\/protected UART access for thread safety
\item Multiplexed channel selection via MCP23017
\item Hardware v1.\+0.\+0 pin swap compensation
\item Per-\/channel calibration with EEPROM persistence
\item Cached measurements and uptime tracking
\item Total current sum for overcurrent protection
\item Queue-\/based logging (no direct printf)
\end{DoxyItemize}

Hardware Configuration\+:
\begin{DoxyItemize}
\item 8 HLW8032 ICs sharing UART0 RX (4800 baud)
\item Individual TX lines selected by 74HC4051 multiplexer
\item Multiplexer control via MCP23017 port B (MUX\+\_\+\+A/\+B/C, MUX\+\_\+\+EN)
\item Frame format\+: 24 bytes starting with 0x55 0x5A
\end{DoxyItemize}
