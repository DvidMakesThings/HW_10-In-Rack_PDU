\doxysubsubsection{Detailed Description}
HTTP handlers for configuration preset management and apply-\/on-\/startup. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/01-\/01
\end{DoxyDate}
This module provides REST API endpoints for managing relay configuration presets. Users can save current relay states as named presets, recall them instantly, and configure a preset to apply automatically on device boot.

Supported Endpoints\+:
\begin{DoxyItemize}
\item GET /api/config-\/presets\+: List all saved presets and current startup selection
\item POST /api/config-\/presets\+: Save or delete a preset
\item POST /api/apply-\/config\+: Apply a preset immediately to relay outputs
\item POST /api/startup-\/config\+: Set or clear the apply-\/on-\/startup preset
\end{DoxyItemize}

Preset Storage\+:
\begin{DoxyItemize}
\item Up to 5 presets (USER\+\_\+\+OUTPUT\+\_\+\+MAX\+\_\+\+PRESETS = 5)
\item Each preset stores\+: name (up to 25 chars), 8-\/bit relay mask (0-\/255)
\item Stored in EEPROM via Storage\+Task for persistence across reboots
\item RAM cache maintained by Storage\+Task for fast access
\end{DoxyItemize}

Relay Mask Encoding\+:
\begin{DoxyItemize}
\item Each bit represents one relay channel (bit 0 = channel 1, bit 7 = channel 8)
\item 1 = ON, 0 = OFF
\item Example\+: 0b00001111 (15) = channels 1-\/4 ON, 5-\/8 OFF
\end{DoxyItemize}

Apply-\/on-\/\+Startup Feature\+:
\begin{DoxyItemize}
\item One preset can be designated as the "{}startup preset"{}
\item If set, this preset applies automatically during Init\+Task
\item Ensures consistent power state after reboot or power cycle
\item Can be cleared to disable automatic application
\end{DoxyItemize}

Overcurrent Protection Integration\+:
\begin{DoxyItemize}
\item Apply operations check \doxylink{group__tasks08_ga4bf47606df6e10c610300fdf1a2573b5}{Overcurrent\+\_\+\+Is\+Switching\+Allowed()} before switching
\item Returns 503 Service Unavailable if overcurrent lockout is active
\item Prevents potentially unsafe relay operations during overcurrent conditions
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item All EEPROM operations routed through Storage\+Task (eeprom\+Mtx protected)
\item All HTTP handlers called from Net\+Task context
\item Relay operations dispatched to Switch\+Task via non-\/blocking queue
\end{DoxyItemize}

\begin{DoxyNote}{Note}
All responses include CORS headers for browser-\/based automation. 

Preset names are JSON-\/escaped for safety. 

Changes are persistent; stored in EEPROM and survive reboots.
\end{DoxyNote}
