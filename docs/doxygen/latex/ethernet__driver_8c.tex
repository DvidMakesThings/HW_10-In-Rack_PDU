Unified RTOS-\/compatible W5500 driver combining HAL, SPI, and configuration. Thread-\/safe with Free\+RTOS mutex protection for all SPI operations.

v1.\+2.\+0 Changes\+:
\begin{DoxyItemize}
\item CRITICAL\+: Added timeout protection to \doxylink{group__drivers03_gaddeb179a48abf7a94ba651742d77c24d}{w5500\+\_\+get\+\_\+tx\+\_\+fsr()} and \doxylink{group__drivers03_gad4b8fcc33da68070ad8208da41838d4c}{w5500\+\_\+get\+\_\+rx\+\_\+rsr()} to prevent infinite loops during heavy network traffic
\item PERFORMANCE\+: Replaced byte-\/by-\/byte SPI with bulk transfers using spi\+\_\+write\+\_\+blocking() and spi\+\_\+read\+\_\+blocking() for multi-\/byte operations
\item Added \doxylink{ethernet__driver_8c_a4b0b3b259cf8981cc3fe59199ffd8f70}{w5500\+\_\+read\+\_\+reg16()} for efficient 16-\/bit register reads
\item Reduced SPI overhead by \texorpdfstring{$\sim$}{\string~}4x for bulk data transfers
\end{DoxyItemize}
