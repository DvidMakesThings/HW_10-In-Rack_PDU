\doxysubsubsection{Detailed Description}
Centralized power state management and standby mode control. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/17
\end{DoxyDate}
This module provides centralized power state management for the ENERGIS PDU, implementing a software-\/based standby mode that reduces power consumption and network activity while maintaining system responsiveness for wake events.

The power manager maintains a global state that all tasks can query to adapt their behavior between normal operation (RUN) and low-\/power (STANDBY) modes. State transitions are atomic and coordinated across hardware peripherals.

Standby Mode Characteristics\+:
\begin{DoxyItemize}
\item W5500 Ethernet controller held in hardware reset (PHY disabled, no traffic)
\item All relay outputs disabled
\item Display LEDs off except PWR\+\_\+\+LED (breathing pattern)
\item Selection LEDs disabled
\item Tasks continue executing but skip non-\/critical operations
\item Watchdog remains serviced to prevent unexpected resets
\item System remains responsive to button press wake events
\end{DoxyItemize}

Wake from standby is typically triggered by a short press of the power button, which calls \doxylink{group__misc3_gafa726e9d0fc140faa3f54c6905ac2520}{Power\+\_\+\+Exit\+Standby()} to restore normal operation.

void Power\+\_\+\+Enter\+Standby (\begin{DoxyParamCaption}\item[{void}]{}{}\end{DoxyParamCaption})}



Enter standby mode. 

Transitions the system from RUN to STANDBY state. Performs\+:
\begin{DoxyItemize}
\item Turn off all relay outputs (all channels OFF)
\item Set all MCP23017 display outputs to 0 except PWR\+\_\+\+LED
\item Hold W5500 RESET low (chip held in reset, network down)
\item All LEDs off except PWR\+\_\+\+LED (which pulses)
\item Set internal power state to PWR\+\_\+\+STATE\+\_\+\+STANDBY
\end{DoxyItemize}

Tasks are NOT suspended; they must detect the new state via \doxylink{group__misc3_gad3252fba1863d278f2611cad531177f5}{Power\+\_\+\+Get\+State()} and switch to minimal operation (heartbeat + delay only).

\begin{DoxyNote}{Note}
This function is typically called by Button\+Task on long press of BUT\+\_\+\+PWR
\end{DoxyNote}

Exit standby mode and return to normal operation. 

Transitions the system from STANDBY to RUN state. Performs\+:
\begin{DoxyItemize}
\item Release W5500 RESET (drive high)
\item Restore normal LED state machine
\item Set internal power state to PWR\+\_\+\+STATE\+\_\+\+RUN
\item Relays remain OFF; user must turn them on explicitly
\end{DoxyItemize}

After calling this function, Net\+Task will detect the state change and reinitialize the W5500 using its existing link-\/detection and reinit logic.

Service the PWR\+\_\+\+LED pulse animation in standby mode. 

Should be called periodically (e.\+g., every 10-\/50ms) when in STANDBY to update the PWR\+\_\+\+LED fade in/out pattern. Has no effect in RUN mode. Implements a simple software PWM by toggling the LED at varying rates to create a breathing effect.

\begin{DoxyNote}{Note}
Call this from a task that runs frequently (e.\+g., Button\+Task scan loop)
\end{DoxyNote}
\begin{DoxyReturn}{Returns}
None
\end{DoxyReturn}
Service the PWR\+\_\+\+LED pulse animation in standby mode.

In RUN mode\+:
\begin{DoxyItemize}
\item PWR\+\_\+\+LED state is maintained (no I2C writes needed -\/ already set).
\item PROC\+\_\+\+LED (GPIO28) PWM output is forced to 0\% duty (off).
\item CRITICAL\+: This function does NO I2C operations in RUN mode to avoid mutex contention with Switch\+Task during SNMP stress testing.
\end{DoxyItemize}

In STANDBY mode\+:
\begin{DoxyItemize}
\item PWR\+\_\+\+LED blinks at 0.\+5 Hz (1 s ON / 1 s OFF, 2 s total period).
\item PROC\+\_\+\+LED outputs a synchronized "{}heartbeat"{} brightness pulse using PWM on GPIO28 with the same 2 s total period as the PWR\+\_\+\+LED blink.
\end{DoxyItemize}
