Main console task function. 

Continuously polls USB-\/\+CDC for character input, accumulates complete command lines, and dispatches them to handler functions. Supports power management by suspending command processing in standby mode while maintaining heartbeat.

Operation Modes\+:
\begin{DoxyItemize}
\item RUN\+: Normal operation with active USB-\/\+CDC polling and command processing
\item STANDBY\+: Suspended operation with reduced heartbeat rate, no command processing
\end{DoxyItemize}

Input Handling\+:
\begin{DoxyItemize}
\item Polls USB-\/\+CDC at CONSOLE\+\_\+\+POLL\+\_\+\+MS intervals (non-\/blocking)
\item Accumulates characters until CR or LF received
\item Supports backspace/delete for line editing
\item Dispatches complete lines to command parser
\end{DoxyItemize}

Power Management\+:
\begin{DoxyItemize}
\item Detects power state transitions automatically
\item Suspends all USB-\/\+CDC operations in standby
\item Maintains reduced heartbeat rate to prevent watchdog timeout
\item Resumes normal operation on exit from standby
\end{DoxyItemize}
