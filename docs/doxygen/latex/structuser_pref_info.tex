\doxysubsection{Detailed Description}
User preferences data structure for device identification and display settings. 

Stores user-\/configurable device metadata and display preferences. Used for SNMP sys\+Name/sys\+Location, web interface identification, and temperature unit conversion. Protected by CRC-\/8 checksum with automatic fallback to defaults on corruption.

Fields\+:
\begin{DoxyItemize}
\item device\+\_\+name\+: 32-\/byte null-\/terminated device identification string
\begin{DoxyItemize}
\item Default\+: "{}\+ENERGIS PDU"{}
\item Used in\+: SNMP sys\+Name, web interface header
\item Max\+: 31 displayable characters + null terminator
\end{DoxyItemize}
\item location\+: 32-\/byte null-\/terminated physical location string
\begin{DoxyItemize}
\item Default\+: "{}\+Unknown"{}
\item Used in\+: SNMP sys\+Location, web interface
\item Max\+: 31 displayable characters + null terminator
\end{DoxyItemize}
\item temp\+\_\+unit\+: 1-\/byte temperature display unit selector
\begin{DoxyItemize}
\item 0 = Celsius (default)
\item 1 = Fahrenheit
\item 2 = Kelvin (reserved for future use)
\item Applied to\+: Web interface, SNMP temperature OIDs
\end{DoxyItemize}
\end{DoxyItemize}

Storage Format\+:
\begin{DoxyItemize}
\item Total size\+: 65 bytes (before CRC appended)
\item EEPROM layout\+: \doxylink{group__config06_ga9d2b9acc4ecae77e01440a5143a61446}{device\+\_\+name(32)} + \doxylink{structuser_pref_info_a00adf96c6e20b5170a8e988ae0b37dda}{location(32)} + \doxylink{structuser_pref_info_ab401582a1a0cf34c9ff0d28871d1417b}{temp\+\_\+unit(1)} + CRC-\/8(1)
\item CRC calculated over first 65 bytes

\end{DoxyItemize}
