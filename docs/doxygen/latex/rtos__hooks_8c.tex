\doxysubsection{Detailed Description}
Free\+RTOS hook implementations, crash breadcrumbs, and scheduler canaries. 

\begin{DoxyAuthor}{Author}
Dvid\+Makes\+Things -\/ David Sipos
\end{DoxyAuthor}

\begin{DoxyDate}{Date}

\end{DoxyDate}
Implementation of Free\+RTOS application hooks and fault handlers. This module captures fault context into watchdog scratch registers for post-\/mortem analysis and provides scheduler liveness monitoring via Idle task canary.

All fault handlers follow a consistent pattern\+:
\begin{DoxyEnumerate}
\item Write fault signature (0x\+BEEF + cause code) to scratch\mbox{[}0\mbox{]}
\item Capture minimal context (LR, task handle, etc.) to remaining scratch registers
\item Initiate controlled reboot via Health module
\end{DoxyEnumerate}

@project ENERGIS -\/ The Managed PDU Project for 10-\/Inch Rack @github \href{https://github.com/DvidMakesThings/HW_10-In-Rack_PDU}{\texttt{https\+://github.\+com/\+Dvid\+Makes\+Things/\+HW\+\_\+10-\/\+In-\/\+Rack\+\_\+\+PDU}}

This module provides\+:
\begin{DoxyItemize}
\item Minimal post-\/mortem breadcrumbs stored in RP2040 watchdog scratch registers on fatal hooks.
\item An Idle-\/hook canary that advances whenever the Idle task runs, used to detect scheduler stalls.
\item Lightweight accessors to read the canary and correlate last Idle timestamp.
\end{DoxyItemize}

All routines are non-\/blocking and safe for RP2040. Reboots use the watchdog path.
