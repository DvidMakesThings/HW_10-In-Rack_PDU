\doxysubsection{Detailed Description}

\end{DoxyDate}
Complete rewrite of MCP23017 driver with simplified, deterministic design.

Key Changes from v1.\+x\+:
\begin{DoxyItemize}
\item Removed redundant bus mutex (per-\/device mutex is sufficient)
\item Simplified I2C operations with clear retry logic
\item Direct error reporting to caller
\item Cleaner separation of concerns
\end{DoxyItemize}

Thread Safety\+:
\begin{DoxyItemize}
\item Each device has its own mutex
\item All public APIs acquire mutex before I2C operations
\item Shadow registers prevent torn read-\/modify-\/write
\end{DoxyItemize}
