\doxysubsubsection{Detailed Description}
USB-\/\+CDC console command interface for system control and diagnostics. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/08
\end{DoxyDate}
This module implements a command-\/line interface accessible via USB-\/\+CDC for PDU configuration, control, and diagnostics. The console provides comprehensive access to system functions including relay control, power monitoring, calibration, network configuration, and firmware management.

Architecture\+:
\begin{DoxyItemize}
\item Polls USB-\/\+CDC interface at configurable intervals without using interrupts
\item Accumulates characters into line buffer with backspace support
\item Parses complete lines and dispatches to command handlers
\item Commands execute directly or interact with other tasks via queues
\item Supports standby mode with suspended command processing
\end{DoxyItemize}

Command Categories\+:
\begin{DoxyItemize}
\item General\+: System information, temperature, reboot, bootloader access
\item Output Control\+: Channel switching, overcurrent status and reset
\item Measurement\+: Power data reading, calibration procedures
\item Network\+: IP configuration, network information display
\item Debug\+: Advanced diagnostics, EEPROM operations, provisioning
\end{DoxyItemize}

Input Handling\+:
\begin{DoxyItemize}
\item Line-\/based command input with CR/\+LF termination
\item Backspace/delete key support for editing
\item Case-\/insensitive command matching
\item Automatic argument parsing and validation
\end{DoxyItemize}

Power Management\+:
\begin{DoxyItemize}
\item Automatically suspends in standby mode to conserve power
\item Reduced heartbeat rate during standby
\item Resumes normal operation on exit from standby
\end{DoxyItemize}

Base\+Type\+\_\+t Console\+Task\+\_\+\+Init (\begin{DoxyParamCaption}\item[{bool}]{enable}{}\end{DoxyParamCaption})}



Initialize and start the console task. 

Creates the Console\+Task Free\+RTOS task, initializes USB-\/\+CDC polling, sets up inter-\/task message queues, and prepares the command dispatcher. Implements deterministic initialization with logger readiness gate.

Initialization Sequence\+:
\begin{DoxyEnumerate}
\item Waits for Logger\+Task readiness with timeout
\item Creates message queues for inter-\/task communication
\item Spawns Console\+Task with configured priority
\item Task begins USB-\/\+CDC polling and command processing
\end{DoxyEnumerate}

Message Queues Created\+:
\begin{DoxyItemize}
\item q\+\_\+power\+: Power/relay control commands (8 messages deep)
\item q\+\_\+cfg\+: Configuration storage operations (8 messages deep)
\item q\+\_\+meter\+: Meter reading requests (8 messages deep)
\item q\+\_\+net\+: Network configuration commands (8 messages deep)
\end{DoxyItemize}


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em enable} & Set true to initialize and start task, false to skip initialization deterministically without side effects.\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
pd\+PASS on successful initialization or when skipped (enable=false). 

pd\+FAIL if initialization fails (queue creation, task creation).
\end{DoxyReturn}
\begin{DoxyNote}{Note}
Call after \doxylink{group__tasks05_gaae3080c72dfa5993e5e495fd767e32c9}{Logger\+Task\+\_\+\+Init()} in boot sequence (step 2/6). 

Use \doxylink{group__tasks02_gab2d019f35eb9844ccb157488ed577f8f}{Console\+\_\+\+Is\+Ready()} to verify initialization before dependent tasks. 

Logs error codes to error logger on failure.
\end{DoxyNote}
