\doxysubsubsection{Detailed Description}
Hardware abstraction layer for front-\/panel pushbutton controls and selection LEDs. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/06
\end{DoxyDate}
This driver provides low-\/level access to the ENERGIS PDU front panel controls\+:
\begin{DoxyItemize}
\item Three pushbuttons (PLUS, MINUS, SET) with active-\/low inputs and pull-\/ups
\item Eight channel selection LEDs driven via MCP23017 GPIO expander
\end{DoxyItemize}

The driver uses direct GPIO access for button reads and delegates LED control to Switch\+Task for thread-\/safe I2C operations. All functions are non-\/blocking and safe to call from any task context.

Hardware Configuration\+:
\begin{DoxyItemize}
\item Buttons are active-\/low with internal pull-\/ups
\item Selection LEDs are controlled via Switch\+Task message queue
\item No debouncing is performed (handled by Button\+Task)
\end{DoxyItemize}
