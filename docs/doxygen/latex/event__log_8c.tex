Append one 16-\/bit event code to a ring buffer region in EEPROM. 

Ring buffer structure for a given region\+:
\begin{DoxyItemize}
\item \mbox{[}base .. base + 1\mbox{]} \+: uint16\+\_\+t write pointer (entry index)
\item \mbox{[}base + EVENT\+\_\+\+LOG\+\_\+\+POINTER\+\_\+\+SIZE\mbox{]} \+: first EVENT\+\_\+\+LOG\+\_\+\+ENTRY\+\_\+\+SIZE-\/byte entry
\end{DoxyItemize}

The buffer is append-\/only with wrap-\/around. If the stored pointer is out of range, it is clamped to 0 and overwritten.

CRITICAL\+: Must be called with eeprom\+Mtx held!
