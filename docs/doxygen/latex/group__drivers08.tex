\doxysubsubsubsection*{Public API}
Create and initialize a socket

Creates a new socket with the specified protocol and port. For TCP, the socket is put into SOCK\+\_\+\+INIT state. For UDP, the socket is put into SOCK\+\_\+\+UDP state.


\begin{DoxyParams}{Parameters}
{\em sn} & Socket number (0-\/7) \\
\hline
{\em protocol} & Protocol type\+:
\begin{DoxyItemize}
\item Sn\+\_\+\+MR\+\_\+\+TCP\+: TCP socket
\item Sn\+\_\+\+MR\+\_\+\+UDP\+: UDP socket
\item Sn\+\_\+\+MR\+\_\+\+IPRAW\+: IP raw socket
\item Sn\+\_\+\+MR\+\_\+\+MACRAW\+: MAC raw socket 
\end{DoxyItemize}\\
\hline
{\em port} & Local port number (0 = auto-\/assign from 0x\+C000) \\
\hline
{\em flag} & Socket flags (SF\+\_\+xxx combinations)\+:
\begin{DoxyItemize}
\item TCP\+: SF\+\_\+\+TCP\+\_\+\+NODELAY, SF\+\_\+\+IO\+\_\+\+NONBLOCK
\item UDP\+: SF\+\_\+\+IGMP\+\_\+\+VER2, SF\+\_\+\+MULTI\+\_\+\+ENABLE, SF\+\_\+\+UNI\+\_\+\+BLOCK, SF\+\_\+\+IO\+\_\+\+NONBLOCK
\item MACRAW\+: SF\+\_\+\+ETHER\+\_\+\+OWN 
\end{DoxyItemize}\\
\hline
