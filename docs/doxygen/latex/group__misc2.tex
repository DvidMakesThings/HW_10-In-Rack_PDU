Log detailed reset cause information at boot. 

Reads RP2040/\+RP2350 hardware reset cause registers and outputs comprehensive diagnostics including chip reset flags, watchdog reason, and scratch register contents. This function decodes and reports\+:
\begin{DoxyItemize}
\item Chip reset flags (POR, RUN, Watchdog, VREG, Temperature)
\item Watchdog reason register
\item All 8 watchdog scratch registers
\item Fault context breadcrumbs if present (0x\+BEEF signature)
\end{DoxyItemize}

If a fault signature is detected in scratch\mbox{[}0\mbox{]}, the function decodes the fault type (Hard\+Fault, Stack\+Overflow, Malloc\+Fail, Assert) and prints the associated context from the remaining scratch registers.

\begin{DoxyReturn}{Returns}
None
\end{DoxyReturn}
\begin{DoxyNote}{Note}
This function is read-\/only and does not modify hardware state. 

Platform-\/specific to RP2040/\+RP2350; gracefully handles other platforms. 

Call this after logger initialization for diagnostic output.
\end{DoxyNote}

Apply network configuration from storage to W5500 Ethernet controller. 

This function bridges the storage layer and the W5500 driver layer by translating the \doxylink{structnetwork_info}{network\+Info} structure into the driver-\/specific configuration format and applying it to the hardware. It performs the following operations\+:
\begin{DoxyItemize}
\item Converts \doxylink{structnetwork_info}{network\+Info} to \doxylink{structw5500___net_config}{w5500\+\_\+\+Net\+Config} format
\item Applies configuration to W5500 hardware registers
\item Initializes the W5500 chip with the new configuration
\item Briefly flashes the Ethernet LED to indicate successful configuration
\end{DoxyItemize}

This abstraction allows Net\+Task to configure networking without direct knowledge of the driver\textquotesingle{}s internal types or initialization sequence.

Capture early boot reset snapshot into retained memory. 

This function must be called as the very first statement in main(), before any subsystem initialization. It captures a minimal diagnostic snapshot into non-\/initialized RAM that survives resets\+:
\begin{DoxyItemize}
\item Validates or initializes the snapshot structure
\item Increments monotonic boot counter
\item Reads raw reset reason bits from hardware
\item Copies all 8 watchdog scratch registers
\end{DoxyItemize}

The snapshot is designed to be captured before any potential initialization failures that might prevent normal logging. It uses no heap, no peripherals beyond hardware register reads, and minimal stack space.

\begin{DoxyReturn}{Returns}
None
\end{DoxyReturn}
\begin{DoxyNote}{Note}
MUST be called before clock configuration, RTOS, logger, or USB initialization. 

Uses noinit RAM section; contents survive across soft resets. 

Pair with \doxylink{group__misc2_ga1224bdfc48804ed50a3c65f98208f8a6}{Helpers\+\_\+\+Late\+Boot\+Dump\+And\+Clear()} to print the snapshot. 
\end{DoxyNote}

Print the early boot snapshot and clear transient diagnostics. 

This function should be called during initialization after the logger subsystem is ready. It outputs the boot snapshot that was captured by \doxylink{group__misc2_ga2481802ac87dc386890d49a5b9f61e0f}{Helpers\+\_\+\+Early\+Boot\+Snapshot()}, including\+:

\item Monotonic boot counter
\item Raw reset reason bits
\item All 8 watchdog scratch register values
\end{DoxyItemize}

After printing, the function clears only the transient diagnostic fields (reset bits and scratch registers) while preserving the magic, version, and boot counter for correlation across subsequent boots.

None
\end{DoxyReturn}
\begin{DoxyNote}{Note}
Call this from initialization task after logger is initialized. 

If no valid snapshot exists, a brief notification is printed. 

The boot counter persists and continues incrementing across boots.
