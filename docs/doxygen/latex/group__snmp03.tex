\doxysubsubsection{Detailed Description}
SNMP outlet control with synchronous operations via Switch\+Task. 

\begin{DoxyVersion}{Version}
2.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/12-\/16
\end{DoxyDate}
This module provides SNMP GET/\+SET callbacks for individual outlet control and bulk operations. All operations use the synchronous Switch\+Task API v2.\+0 to ensure deterministic behavior and accurate SNMP responses.

Key features\+:
\begin{DoxyItemize}
\item Individual outlet control (8 channels, numbered 1-\/8 in SNMP OIDs)
\item Bulk operations (All ON, All OFF)
\item Synchronous operations with hardware read-\/back verification
\item Direct hardware reads (no cache) for GET operations
\item Blocking writes with verification for SET operations
\end{DoxyItemize}

Channel Indexing\+:
\begin{DoxyItemize}
\item SNMP OIDs use 1-\/based indexing (1..8)
\item Internal Switch\+Task API uses 0-\/based indexing (0..7)
\item All callbacks handle conversion transparently
\end{DoxyItemize}

GET Operations\+:
\begin{DoxyItemize}
\item Query current outlet state from hardware via \doxylink{group__tasks11_ga19c6dbf15503e4ca3c985e5acd42c278}{Switch\+\_\+\+Get\+State\+Compat()}
\item Return 4-\/byte INTEGER (0=OFF, 1=ON)
\item Non-\/blocking with mutex protection
\end{DoxyItemize}

SET Operations\+:
\begin{DoxyItemize}
\item Write desired state via \doxylink{group__tasks11_gaef7818ff67a4d2235b897909f9fe6744}{Switch\+\_\+\+Set\+Channel\+Compat()}
\item Block until hardware write completes
\item Automatic verification with up to 500ms polling
\item Error logging for failures
\end{DoxyItemize}

\begin{DoxyNote}{Note}
All functions are RTOS-\/safe and can be called from SNMP agent context. 

Operations may block for up to 500ms during hardware verification.
\end{DoxyNote}
