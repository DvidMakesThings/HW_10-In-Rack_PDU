void v\+Assert\+Called (\begin{DoxyParamCaption}\item[{const char \texorpdfstring{$\ast$}{*}}]{file}{, }\item[{int}]{line}{}\end{DoxyParamCaption})}



Free\+RTOS assertion failure hook with context capture. 

Called when a Free\+RTOS assertion fails (via config\+ASSERT macro). Captures diagnostic context and initiates reboot.

Fault signature format in watchdog scratch registers\+:
\begin{DoxyItemize}
\item scratch\mbox{[}0\mbox{]}\+: 0x\+BEEF0000 \texorpdfstring{$\vert$}{|} 0x\+F4 (Assert signature)
\item scratch\mbox{[}1\mbox{]}\+: Function return address
\item scratch\mbox{[}2\mbox{]}\+: Source line number where assertion failed
\end{DoxyItemize}
