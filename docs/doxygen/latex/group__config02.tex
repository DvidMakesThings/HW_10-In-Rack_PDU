\doxysubsubsection{Detailed Description}
Centralized configuration parameters for W5500 Ethernet controller. 

\begin{DoxyVersion}{Version}
1.\+0.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/11-\/06
\end{DoxyDate}
This file centralizes all configuration for the W5500 Ethernet controller used in the ENERGIS PDU. Configuration includes\+:
\begin{DoxyItemize}
\item Hardware pin assignments and SPI settings
\item Socket memory buffer allocation (16KB TX + 16KB RX total)
\item Network parameters (IP, MAC, gateway, subnet)
\item Protocol support flags (TCP, UDP, SNMP, ICMP)
\item RTOS task and synchronization parameters
\item Advanced TCP/\+IP tuning parameters
\end{DoxyItemize}

Socket Buffer Strategy\+: The W5500 provides 16KB each for TX and RX buffers, distributed across 8 sockets. Current allocation prioritizes HTTP server (Socket 0) and SNMP (Socket 1).

Configuration Philosophy\+:
\begin{DoxyItemize}
\item All hardware-\/specific values come from \doxylink{_c_o_n_f_i_g_8h}{CONFIG.\+h}
\item Runtime-\/changeable parameters (IP, MAC) have defaults
\item Compile-\/time validation prevents buffer overallocation
\end{DoxyItemize}
