Detailed Description

Author
DvidMakesThings - David Sipos
Version
1.1.0
Date
2025-11-08

Implementation of SNMP network configuration getters. This module reads the persisted network configuration from EEPROM via StorageTask and formats network addresses as human-readable strings for SNMP responses.

Formatting conventions:

  • IPv4 addresses: dotted-decimal (e.g., "192.168.1.100")
  • MAC addresses: colon-separated hex (e.g., "02:45:4E:0C:7B:1C")

All functions include error handling with automatic fallback to compiled defaults if storage access fails.
