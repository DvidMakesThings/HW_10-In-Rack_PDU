◆ s_bootsnap

helpers_boot_snapshot_t s_bootsnap
static

Retained snapshot buffer in non-initialized memory.

Placed in a noinit section so its content survives across soft resets. On first power-on it will contain random data until initialized by Helpers_EarlyBootSnapshot().
