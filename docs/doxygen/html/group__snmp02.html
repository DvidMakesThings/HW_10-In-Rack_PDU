Detailed Description

Network configuration exposure via SNMP.

Version
1.1.0
Date
2025-11-08

This module provides SNMP GET callbacks that expose the device's network configuration as read-only OCTET_STRING values. Network parameters are retrieved from persistent storage (EEPROM) via the StorageTask API.

Exposed network parameters:

  • IP address (dotted-decimal notation)
  • Subnet mask (dotted-decimal notation)
  • Gateway address (dotted-decimal notation)
  • DNS server address (dotted-decimal notation)
  • MAC address (colon-separated hexadecimal)

If storage access fails, functions automatically fall back to compiled-in default values to ensure SNMP queries always return valid data.

All functions are RTOS-safe and can be called from the SNMP agent context without blocking other tasks.

Note
These are read-only OIDs; network configuration must be modified via the web interface or console commands.
