Handles POST requests to /api/control endpoint for relay control. Processes form-encoded channel states and labels, applies changes using idempotent relay control functions with logging. Label updates are performed via storage queue for thread safety.

Handles the HTTP request for the control page.

Processes POST requests to /api/control with form-encoded body:

  • channelN (1-8): "on" or "off" for relay state
  • labelN (1-8): Channel label string (max 25 chars)
Parameters
sockThe socket number
bodyThe request body (form-encoded)

@http

  • 400 Bad Request: Missing body
  • 503 Service Unavailable: Overcurrent lockout prevents switching ON
  • 200 OK: Success with "OK\n" body

Handles the HTTP request for the control page.

Parameters
sockThe socket number
bodyForm-encoded POST body (e.g., "channel1=on&channel3=off&label1=MyDevice")
  • Parses form-urlencoded fields: channelN and labelN where N=1..8.
  • Channel semantics: "on" -> relay ON "off" or missing -> relay OFF
  • Label semantics: If labelN field is present, updates the channel label via storage queue. Labels are truncated to 25 characters max.

@http

  • 400 Bad Request if body is missing.
  • 503 Service Unavailable if overcurrent lockout prevents switching ON.
  • 200 OK on success with "OK\n" text body.
