Detailed Description

Fixed threshold offsets for overcurrent state machine.

These thresholds are fixed offsets applied to the regional current limit. The actual limit (10A EU / 15A US) is determined at runtime from EEPROM.

State Machine:

  • NORMAL: Current < (LIMIT - WARNING_OFFSET)
  • WARNING: Current >= (LIMIT - WARNING_OFFSET)
  • CRITICAL: Current >= (LIMIT - SAFETY_MARGIN)
  • LOCKOUT: Trip executed, switching disabled
  • RECOVERY: Current < (LIMIT - RECOVERY_OFFSET)
