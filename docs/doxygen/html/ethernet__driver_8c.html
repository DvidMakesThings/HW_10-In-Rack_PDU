Detailed Description

Author
DvidMakesThings - David Sipos
Version
1.2.0
Date
2025-12-10

Unified RTOS-compatible W5500 driver combining HAL, SPI, and configuration. Thread-safe with FreeRTOS mutex protection for all SPI operations.

v1.2.0 Changes:

  • CRITICAL: Added timeout protection to w5500_get_tx_fsr() and w5500_get_rx_rsr() to prevent infinite loops during heavy network traffic
  • PERFORMANCE: Replaced byte-by-byte SPI with bulk transfers using spi_write_blocking() and spi_read_blocking() for multi-byte operations
  • Added w5500_read_reg16() for efficient 16-bit register reads
  • Reduced SPI overhead by ~4x for bulk data transfers
